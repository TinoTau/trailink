第一阶段之后陆续加入并已完成：

- Cookie 登录与三类角色；公司、调度员、司导的申请与批准；人员名单不跨人共享。
- 公司「派给调度」：整单交给调度员，订单池，收回公司池。
- 调度台：创建订单（框选，最多三个月）、未分配 / 所有订单、拖拽整单与按天派单、拆单、冲突图案、司导详情、取消自己派出的日期。
- 我的行程：领取订单、框选自建单（占位单）、取消行程；真实订单自动覆盖占位单。
- 四种备注（各人调度备注、司导备注、共用备注、给司导 / 调度员的备注），公司简称。
- 公司信息页、个人信息页（姓名、联系方式、用户名、密码、头像、驾照正反面）。
- 车辆：每人自己的车辆、照片、车辆日历、绑定到行程日、车辆冲突。
- 住宿位置浮雕与透明度滑条。
- 订单附件 7 天后自动清理。

## 4. 天气预报（2026-11-01 完成，未发布）

- 「我的行程」日期格显示天气。默认用 MET Norway（免费、允许商用）；MetService、Open-Meteo 保留实现，买了商用订阅后可通过 `Weather:Source` 切换。共查 10 个地点；当天有库克山项目时显示库克山机场的天气，有峡湾项目时显示米尔福德峡湾的天气。
- 发布前要做：不需要密钥，后端更新后自动开始查 MET Norway。云端服务器要能访问 `api.met.no`。不需要改云端库。
- 这次发布前后端必须一起更新（行程日接口多了 `weather`，地点按钮改读 `GET /api/places`）。
