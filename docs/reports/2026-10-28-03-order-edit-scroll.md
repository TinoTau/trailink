# 手机上订单编辑可以滑到下面

## 目标

调度台在手机上打开订单编辑时，下面的编辑项被裁掉，无法下拉。

## 改动

- 编辑表单原来放在卡片标题里。标题禁止触屏滑动，卡片又把超出的部分裁掉。
- `DispatcherCalendarCard.tsx`：订单编辑和当日备注改到卡片里原来就滚动的区域顶部。打开编辑时滚回顶部。
- `dispatcher.css`：这块区域继续用触摸滚动。
- `docs/FRONTEND_DESIGN.md` 写明编辑项在可滚动区域里。

## 命令结果

- 390×844 打开林调度的一张订单并点编辑。滚动区域高 299，内容高 665。未滚动时「上传截图」在可视区域外，下拉 80 像素后进入可视区域。
- 没有保存订单。`tsc -b` 通过。
