# 框选日期时日历跟着滚动

## 目标

创建订单拖选很多天时，日历跟着当前选中的位置滚动，不用盲拖。

## 改动

- 拖选靠近日历上沿或下沿，或拖出日历时，日历按手指方向滚动，并把当前碰到的日期收进选区。松手后停止。
- 调度台创建订单和我的行程框选建单用同一套滚动。选区仍然只认这张日历里的日期。
- 说明、PRD、前端设计和开发计划已写上这句话。

## 命令结果

- 前端 `tsc -b --noEmit`：通过。
- 浏览器：创建订单从 10月31日往日历下方拖，日历从 1760 滚到 2442，选区变成 10月31日到 1月28日，画面停在 1月。松手后不再滚动。没有提交，没有新订单。所有订单仍是 CC-test001、CC-test002、CC-test003。没有点 Mason。
- 我的行程用的是同一套滚动，这次没有在那个页面上再拖一遍。
