# 清空库并写入演示数据

## 目标

清空业务表，用现有公司 / 成员 / 订单写入一套可登录的交叉归属数据，方便核对三类角色看到的内容。

## 对应模块

1. 现有模块：`companies`、`users`、`company_members`、`drivers`、`orders`、`itinerary_days`。
2. 改动文件：`DemoDataSeeder.cs`、`Program.cs`（`--seed-demo`）、公司桌面成员过滤与失效 `companyId` 回退。
3. 不另建种子库或平行订单表。
4. 命令：`dotnet run -- --seed-demo`。密码均为 `Passw0rd!`。

## 账号

| 角色 | 用户名 | 看到什么 |
|---|---|---|
| 公司 | `north` `south` `central` | 本公司信息、2 名调度员、本公司全部订单；`north` 有蒋司导待批 |
| 调度 | `chen` 北岛+中部；`lin` 北岛；`huang` 南岛+中部；`wu` 南岛 | 调度台；公司页下拉自己的公司；只能改不了批准 |
| 司导 | `drv01`–`drv13` | 自己的行程日历；公司页下拉所属公司，只看自己跑过的单 |
| 待批 | `drv14` | 已申请北岛 |

交叉：`drv05` 刘司导属三家公司；陈/林/黄都派过他。陈：drv01–05；林：drv03–07；黄：drv05,08–11；吴：drv09–13。

订单：每家有未派的未来单；9 月历史已完成；10 月底起有进行中已派。

## 命令结果

- 种子写入成功。
- 接口核对：`north` 调度员=陈、林，申请=蒋，订单 13；`chen` 两家公司且 `canManage=false`；`drv05` 三家公司。
- 浏览器：`drv05` 公司页下拉三家，只显示自己的行程图标；日历只有司导入口。
