# 车辆：一键找出未配车的司导

## 需求

车辆管理里一键展示还有哪些订单没配车：只看当前调度员已派给司导、但还没配车的日期；没派单的订单不算；订单标签不提示（车辆和订单管理相对独立）。

## 设计

不新开页面，也不改配车方式（仍是把车辆拖到司导日历），只把要处理的司导筛出来：

- 车辆标签按钮行加「未配车 N」（N = 有缺车日期的订单数）。
- 点开后司导区只留有缺车日期的司导，最早缺车的在前，左上角「缺 N 天」。
- 打开司导时日历跳到他第一个未配车的日期。
- 配好车后看板刷新，数字跟着减少。

## 改动（只改前端）

- `DispatcherPage.tsx`：`missingVehicles` 从看板订单汇总（有司导、没车、日期 ≥ 今天、是自己派出的），按司导记天数和最早日期，同时数订单数；`missingOnly` 开关；`paneDrivers` 在开关打开且在车辆标签时过滤和排序；`toggleDriver` 打开司导时跳到最早缺车日期。
- `OrderPane.tsx`：车辆按钮行加「未配车 N」，提示文字补一句说明。
- `DriverPane.tsx`：`missingDays` 角标和空列表文字。
- `dispatcher.css`：角标、红字和禁用样式。
- PRD 第 7 节、FRONTEND_DESIGN 7.8 更新。

## 验证

- `tsc -b`、`npm run build` 通过。
- 沙盒界面测试（桌面 1366 宽、手机 390 宽）：调度员名单里 4 位司导、2 辆车，造了 5 张单：
  - 李：已派 3 天没车 → 「缺3天」；
  - 张：已派 3 天，2 天有车、1 天没车 → 「缺1天」，最早，排第一；
  - 赵：已派且全配车，另有一张过去的单没车 → 不出现；
  - 一张没派司导的单 → 不算。
  - 按钮显示「未配车 2」；打开张，日历跳到他缺车那天并显示「未配车」；给那天配车后刷新，变成「未配车 1」，只剩李。页面无报错。
