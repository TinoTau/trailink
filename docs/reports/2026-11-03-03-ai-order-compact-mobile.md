# AI 建单核对页：手机上紧凑

## 需求

核对页要能在手机上方便操作，整体和相关内容都要更紧凑。

## 改动（只改前端 `AiOrderCard.tsx`、`ai-order.css`）

- 新增 `InlineText`：内容平时显示成小字文字，点一下变输入框，离开 / 回车保存。手机上输入框必须 16px 才不会放大整页（见 2026-10-27-16），所以只有正在编辑的那一个是大字，其余保持 13px。
- 时间改成 `InlineText` + 24 小时制解析：「签 10:40」「始 11:00」。
- AI 提醒收成一行，可展开；副标题缩短。
- 订单号、人数、备注放进一块浅灰底。
- 每天不再套卡片，改为细线分隔；「+ 活动」挪到日期那一行；行程和活动缩进对齐。
- 活动整行：标签、名称、两个时间、电子票小标签（透明下拉盖在上面）、删除。
- 手机上卡片铺满整屏、无外框；底部留出安全区。
- 悬停底色只在有鼠标的设备上出现（触屏点过不再一直灰着）。
- FRONTEND_DESIGN 7.6b 更新。

## 验证

- `tsc -b`、`npm run build` 通过。
- 沙盒界面（假 Claude 接口）：390 宽手机一屏从约 2 天变成约 5 天；点行程进入编辑、改完离开保存；时间 915 → 09:15、25:99 退回、10.40 → 10:40；生成订单正常，无页面报错。桌面 1366 宽同样检查。
