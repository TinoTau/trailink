# 登录密码框不再把手机页面放大

## 目标

按手机宽度实际登录一次，查清页面尺寸为什么还是不对。

## 改动

- 用林调度在 390×844 的页面登录。用户名输入框是 16px，密码框仍是 14px。密码框套在带图标的外层里，字号从外层继承，手机浏览器一点密码就会放大整页。
- `frontend/src/pages/login.css`、`frontend/src/index.css`：窄屏和触屏上，带图标的输入框及其内部输入都用 16px。
- `frontend/index.html`：视口固定为设备宽度、缩放 1 倍。去掉会在键盘弹出时改页面高度的设置。登录成功后只取消焦点，不再来回改视口。
- `docs/FRONTEND_DESIGN.md` 同步。

## 命令结果

- 改完后密码框为 16px。再次登录进入林调度的调度台，缩放比例是 1，页面宽 390，没有横向溢出。

## 未做

- 没有打包，没有上传。桌面浏览器无法复现苹果手机聚焦后的真实缩放。

无。
