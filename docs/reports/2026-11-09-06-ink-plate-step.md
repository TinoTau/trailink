# 我的行程控制条加「车牌」挡 2026-11-09

## 需求

司导界面（我的行程）的纵向控制条：
- 原来拉到底是背景字和天气，拉到顶是日期和公司。
- 现在往上再加一挡：显示日期和车牌；这一天没配车就只显示日期。

## 改动（只改前端，后端行程日本来就带 `vehiclePlate`）

- `calendarInk.tsx`：
  - `useCalendarInk` 新增 `plate` / `setPlate`。
    - 进车牌挡时透明度同时设为 1（和最上面一样清楚）。
    - 往下调透明度时自动退出车牌挡。
    - 记在 `trailink.calendar.inkPlate`。
  - `CalendarInkBar` 新增 `plateStep`：
    - 原来的整段压在条的下面 80%，刻度线以上是车牌挡；
    - 点或拖过刻度和顶端的中点就进车牌挡，滑块吸到顶；
    - 键盘：在最上面再按上键进车牌挡。
    - 没有 `plateStep` 的控制条（调度台）不变。
- `calendarDay.css`：刻度线；车牌挡时刻度和滑块变蓝。
- `types.ts`：`DriverCalendarDay.vehiclePlate`。
- `DriverCalendarPage.tsx`：
  - 按天汇总车牌，同一天多张单配了不同的车用「/」连起来；
  - 控制条打开 `plateStep`；
  - 车牌挡时日期下面写车牌，没配车只显示日期。
- `localPrefs.ts`：新增偏好键。
- 文档：FRONTEND_DESIGN 透明度一节。

## 验证

- `tsc -b`、lint 通过。
- 沙盒，司导甲有两天行程：第一天配了车，第二天没配车。在「我的行程」页，桌面 1366×900 和 iPhone 13 模拟各跑一遍。

  | 操作 | 有车那天 | 没车那天 |
  |---|---|---|
  | 默认 | 日期 / 公司 | 日期 / 公司 |
  | 点在刻度下（原来的顶） | 日期 / 公司 | 日期 / 公司 |
  | 点在最上面一挡 | 日期 / 车牌 | 只有日期 |
  | 刷新后 | 仍是车牌挡 | 仍是车牌挡 |
  | 往下点 | 回到日期 / 公司 | 回到日期 / 公司 |

  - 桌面另外试了从下往上拖到顶：进车牌挡。
  - 车牌挡时滑块变蓝。
  - 页面没有报错。
