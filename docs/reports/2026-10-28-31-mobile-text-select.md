# 移动端所有界面都不选择非输入文字

## 目标

触屏或窄屏上，长按输入框以外的地方不选择文字，也不弹出系统菜单。我的行程、调度台、派给调度、公司信息、个人信息和登录都走这一条。输入框仍可选字。已有的长按，例如日历按住约 0.5 秒再拖，保持原样。

## 改动

原先只写在按钮上。司导页的标题、姓名和日期里的「NL林调度」不是靠那条按钮规则盖住的。

- `frontend/src/index.css`、`frontend/src/main.tsx`：同一条规则扩到整个页面。文本框、搜索框、密码框、邮箱、电话、网址、数字、多行文本、下拉框和可编辑区域除外。没有在各页面再写一套。
- `docs/FRONTEND_DESIGN.md`：改成全站说明。

## 验证

手机宽度 390：我的行程标题、姓名和日期文字 `user-select` 为 `none`，选字和长按菜单被拦住。个人信息里的姓名等输入框仍是 `text`，文件选择按钮被拦住。公司信息的标题和公司名被拦住，搜索框和公司下拉框仍可选。调度台的「订单」「司导」、订单图标和司导图标被拦住。派给调度用的是同一张调度台页面。宽屏 1920 上标题恢复为可选。没有改资料，已回到我的行程。
