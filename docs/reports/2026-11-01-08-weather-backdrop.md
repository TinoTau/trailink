# 天气文字移到背景层

## 目标

用户反馈：天气不要在日期文字下面另加一行，要和浮雕字放在同一个背景图层。

## 原因说明：为什么有的日期没有天气

以下日期不显示天气，浮雕字也保持原来的大小：

- 超出预报范围：MET Norway 约 9 天，最后一天预报不完整也不显示。
- 已经过去的日期。
- 住宿地不是常用地点（例如手动输入「库克山」）。
- 调度台查看别人的订单。

## 改动

- `calendarDay.tsx`：有天气时，浮雕字和天气放进同一个背景容器 `calendar-day-backdrop`。没有天气时保持原样。
- `calendarDay.css`：
  - 删掉 `.with-weather`（原来给格子底部加 11px 留白、把日期往上推）。
  - 新增 `.calendar-day-backdrop`，铺满格子、放在背景层：
    - 浮雕字缩到 20px，贴上沿。
    - 天气用 9px 粗体，贴下沿。
    - 和浮雕字同一个透明度变量。
  - 日期和派出人的位置不再变化，照常叠在上面。
- `FRONTEND_DESIGN.md` 同步。

## 命令结果

- `npm run build`：成功。
- `npm run lint`：29 条警告，没有新增。
- 沙盒手机视口（390 宽）截图检查：
  - 每个日期格 48×36 px。
  - 有天气的格子：浮雕字在上，「降雪8mm」「降雨25mm」在下沿，日期和派出人位置和没有天气的格子一致。
  - 手动输入「库克山」的格子仍是原来的大浮雕字。
  - 浏览器控制台没有错误。
