# 移动端按钮不再选择文字

## 目标

触屏长按按钮时不选择文字，也不弹出系统菜单。按钮自己已有的长按保留。没有长按操作的按钮，长按没有任何反应。输入框仍可选中文字。

## 改动

- `frontend/src/index.css`：触屏或窄屏上，按钮禁止选择文字，并关掉系统长按菜单。
- `frontend/src/main.tsx`：同一条件下，按钮上的选字和右键/长按菜单被取消。点到输入框、文本域、下拉框时不拦截。
- `docs/FRONTEND_DESIGN.md`：写明这条规则。日历按住约 0.5 秒再拖选的操作不变。

## 验证

手机宽度的调度台：普通按钮的 `user-select` 为 `none`，长按菜单和选字都被拦住。输入框没有被拦住。创建订单里按住日期约 0.5 秒后，仍出现「添加 10月1日 仅日期」。没有点添加，卡片已关闭，页面仍是暂无订单。
