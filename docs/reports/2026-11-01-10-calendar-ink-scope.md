# 透明度滑条只作用于有浮雕字的日期

## 目标

用户反馈：透明度调低后，没有订单的日期也一起变淡了。用户靠这些日期认时间，全部看不清就分不出哪张订单在哪天。

## 原因

日期文字的透明度变量原来加在所有日期格上，包括空白日期。上一轮把最低值从 0.45 调到 0.08，这个问题就明显了。

## 改动

- `calendarDay.tsx`：有浮雕字（住宿地点）的格子加 `has-place` 类。
- `calendarDay.css`：只有 `has-place` 格子里的日期和派出人跟着滑条变淡。以下日期不受影响，始终清楚：
  - 空白日期。
  - 有订单但没写住宿位置的日期。
- `FRONTEND_DESIGN.md`：补充滑条的作用范围。

调度台司导详情日历用同一个组件，行为一致。

## 命令结果

- `npm run build`：成功。
- `npm run lint`：29 条警告，没有新增。
- 沙盒手机视口截图：
  - 滑条最低：有住宿地点的日期露出浮雕字和天气，日期淡出。6、7、9–15 等空白日期保持清楚。
  - 滑条最高：所有日期都清楚。
