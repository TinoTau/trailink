# 订单名称没有订单号时用共用备注

## 目标

订单名称仍优先用公司订单号。没有订单号时，不再用各自的独立备注，改为共用备注。调度台、我的行程、公司信息、派给调度和冲突提示走同一条。

## 改动

- `orderDisplayLabel` 只认公司订单号和 `sharedNotes`，取第一行，超过 12 字截断。
- 公司信息订单缩略补上 `sharedNotes`，图标才能用到这条。
- 派单冲突提示在没有公司订单号时写共用备注的第一行，不再按角色取各自备注。

## 命令结果

- `tsc -b` 通过。
- `dotnet test --configuration Release --filter Conflict_warning_uses_shared_notes|UpdateDay_failOnConflict`：2 通过。没有订单号时提示含「共用名」，不含换行后的「第二行」，也不含系统订单号。
- 本机调度台「所有订单」里 CC-test001、CC-test002、CC-test003 仍显示公司订单号。筛选项已回到未分配。正在跑的接口响应里还没有 `sharedNotes` 字段，所以浏览器里没能看到「没有订单号时显示共用备注」。
