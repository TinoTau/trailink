# 活动库

## 目标

用户要求开发活动库，让每日行程更方便填写：

- 调度台和我的行程的日期详情里，点「添加活动」弹出选择框，按背景字目的地列出当地活动。
- 选项长按 0.5 秒后可拖动排序，记在用户偏好里；可以多选，显示点选的顺序，确认后按这个顺序加入。
- 日期详情里的活动也是长按 0.5 秒后拖动排序。
- 活动库只有公司账户能在公司信息里添加、编辑，所有公司共用。
  - 添加前先模糊搜索，避免重复。
  - 必须绑定目的地；不常见的目的地可以输入新建，并保存下来供以后搜索。
  - 中英文名分开输入，可以只填一个。
  - 住宿酒店也算活动。
  - 可以加共用备注和图片，图片和车辆照片的逻辑一致。
- 所有用户可以在自己看得到的日期详情里评价、评分；默认按评分排序。

用户确认：

- 每人每项活动一条评分，可以改。
- 个人顺序存在账户上，跨设备同步。
- 一项活动可以绑定多个目的地。
- 保留手动填写；选完之后仍可补时间、承办方、电子票。

## 改动

### 数据库（迁移 `AddActivityLibrary`，只新增）

- `destinations`：7 个常用住宿地点按 `Places.cs` 的固定 Id 写入，`mark` 为浮雕字。其他目的地由公司账户新建。
- `library_activities`、`library_activity_destinations`（多对多）、`library_activity_photos`、`library_activity_ratings`（每人每项一条，1–5 分检查约束）、`user_activity_orders`（每人每个目的地的顺序）。
- `order_activities.library_activity_id`：可空，活动库删除这项时置空，行程里的文字保留。

### 后端

- `Services/ActivityLibrary.cs`：活动库规则只在这里定义。
  - 显示名：中文名优先。
  - 中英文名校验。
  - 模糊搜索：ILIKE，转义 `%` 和 `_`。
  - 同名判断：不区分大小写。
  - 住宿位置对应目的地：常用地点按全名或浮雕字，其他按目的地名称。
  - 评分汇总：一次分组查询。
  - 弹框排序：个人顺序在前，其余按平均分、人数、名称。
- `Controllers/LibraryController.cs`：
  - 目的地：搜索、新建（同名返回已有的）。
  - 活动：搜索、详情、增删改（只限公司账户，其他身份 403）。
  - 选择框列表、保存个人顺序、评分。
  - 图片：最多 3 张，和车辆照片规则一致。
- `OrderActivitiesController`：新增 `POST .../activities/from-library`，按传入顺序加到当天末尾，活动名取当时的快照。
- `Places.cs`：每个常用地点加固定 Id 和英文名。
- `AppFileStore`：新增 `library` 文件夹。

### 前端

- `useHoldReorder.ts`：长按约 0.5 秒后拖动排序，活动选择框和当日活动共用。
  - 按住前手指移动是滚动页面，拖动中不滚动。
  - 拖动结束后吞掉紧跟的那次点击。
- `pages/library/ActivityPicker.tsx`：底部弹出的选择框。
  - 当地活动带评分；多选时圆圈里标出点选先后。
  - 长按拖动后保存到账户。
  - 可以搜索整个活动库，也可以手动填写。
- `pages/library/ActivityReview.tsx`：评价框。
  - 显示共用备注和图片。
  - 我的星级和评价，可以保存或删除。
  - 列出所有人的评价。
- `pages/library/ActivityLibrarySection.tsx` + `LibraryActivityEditor.tsx` + `LibraryPhotos.tsx`：公司信息里的活动库。
  - 搜索、添加、编辑。
  - 输入名称时提示可能已有的活动。
  - 目的地标签、搜索和新建。
  - 共用备注；图片复用 `PhotoViewer`；删除需要两步确认。
- `DriverDayEditor`：
  - 「添加活动」改为打开选择框，选完按点选顺序加入。
  - 已添加的活动改用 `useHoldReorder`，原来是按下即拖。
  - 新增「编辑」（补承办方、时间）和「评价」（只有活动库来的才有）。
  - 按钮换到活动名下一行，避免把名称挤成竖排。
- `DispatcherPage`：点外面关闭卡片的判断，排除活动库弹框（`.library-overlay`），否则在调度台点选项会把卡片关掉。
