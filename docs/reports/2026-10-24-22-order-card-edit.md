# 执行报告：订单卡片编辑信息与行程

## 目标

调度台订单卡片能改公司订单号、备注，并点击某一天用与司导相同的文本活动编辑。不另建接口或编辑页。

## 改动

1. 对应现有模块：调度台 `DispatcherCalendarCard` / `DispatcherPage`，复用 `PUT /api/orders/{id}` 与 `DriverDayEditor`。
2. 订单卡片笔记图标打开「订单信息」：公司订单号写入 `platformOrderNo`，备注写入 `notes`，其余字段保持原值。
3. 点击订单日历某一天，在当月下方打开现有司导日期编辑（自己输入活动文本、可拖排序）。
4. 拖动某一天仍走原派单逻辑；没落到司导时按点击打开编辑。
5. 同步 `docs/FRONTEND_DESIGN.md`、`docs/PRD.md`、`docs/API_CONTRACT.md`、`docs/DEVELOPMENT_PLAN.md`。
6. 不新增实体、不复制 `OrderEditPage`。
