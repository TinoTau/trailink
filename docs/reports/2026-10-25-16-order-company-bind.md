# 订单所属公司绑定

日期：2026-10-25

## 目标

公司建单直接属于本公司。调度员可搜索公司绑定或改绑。改绑后新公司能看到该单。仍用 `orders.company_id`，不另建订单系统。

## 对应现有模块

`OrdersController`、`Order.CompanyId`、`GET /api/companies`、订单信息 `OrderInfoFields`、`PUT /api/orders/{id}`。

## 改动

- 公司 `POST /api/orders` 强制写本公司，不能改绑。
- 调度员可把 `companyId` 设成任意已有公司；`PUT` 再改即换公司。
- 公司 `GET /api/orders` 只返回绑到本公司的单。
- 调度台订单信息增加所属公司搜索；公司账户只读。
- 建单不再用本机记住的公司 id 偷偷绑定。
- 测试 `Dispatcher_can_rebind_order_company`。权威文档已同步。
