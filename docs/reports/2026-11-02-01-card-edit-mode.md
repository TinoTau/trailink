# 调度台：编辑订单时往下滑会接到日历

## 问题

用户反馈：调度台里点开订单、编辑订单信息时，往下拉会直接接到日历，看起来不像一个单独的编辑框。

## 原因

订单卡片（`DispatcherCalendarCard`）点笔记图标后，编辑内容（公司、公司订单号、共用备注、本人备注、订单截图）是插在卡片滚动区的最上面，下面紧接着仍是整份日历（半年前到半年后），所以编辑区和日历连成一条。司导卡片的备注编辑也是同一个组件，情况一样。

## 改动

`DispatcherCalendarCard.tsx`：

- 编辑打开时，卡片滚动区只放编辑内容，不渲染日历，也不显示右侧的浓淡滑条；往下滑到编辑内容末尾为止。
- 打开编辑前记下日历滚到的位置；收起编辑后日历回到原处（不会跳回最早的月份）。
- 编辑中滚动不再带动司导日历对齐。

只改调度台 / 派给调度的订单卡片和司导卡片。我的行程当日详情的订单信息编辑是另一套，不受影响。

## 验证（沙盒，手机视口 + 触屏事件）

- 打开订单：日历 13 个月，停在订单日期（滚动位置 1720）。
- 点笔记图标：卡片里 0 个月、只有编辑内容，可滚动距离从 3069 变成 82，滑到底就是编辑内容末尾。
- 再点收起：日历恢复 13 个月，滚动位置回到 1720。
- 司导卡片同时开着，不受影响。
- 调度台触屏拖拽回归与基准输出完全一致；界面脚本只有创建订单的日期因为过了零点往后顺延一天，其余一致。
- `tsc` 通过；lint 0 错误、28 条警告（不变）；`vite build` 通过，前端入口 `index-BZlCRQic.js`。
