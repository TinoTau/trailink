# 订单记录：公司账户按「整个公司 / 我调度的」过滤 2026-11-10

## 需求

公司账户查看订单记录时，有一个下拉框选择看整个公司的订单，还是自己作为调度员的订单。

## 改动

- 后端 `GET /api/company/orders` 加 `scope`：公司账户传 `desk` 时，只看自己调度台上的单。
  - 用 `OrderRules.OnDesk`，和公司账户调度台（`GET /api/orders?desk=true`）同一条规则。
  - 不传时仍是本公司全部。
  - 调度员、司导传不传都不影响。
- 前端：
  - `companyApi.orders(companyId, scope?)`。
  - `CompanyOrderRecords`：标题挪进组件（「订单记录」一行），公司账户右边一个下拉框「整个公司 / 我调度的」。
    - 选过的记在本机（`trailink.company.recordsScope`），换了就重新读取，并重新停到今天。
    - 「我调度的」为空时写「自己的调度台上还没有订单」。
  - 下拉框样式和页面上的小圆角按钮一致。
  - `CompanyPage` 传 `canFilter`（公司账户、管理的是自己公司）。
- 测试：订单记录测试加 `scope=desk`：只返回公司账户自己派了司导的两张池里的单（在它调度台上），分给调度员的单不在里面。
- 文档：API_CONTRACT、PRD 4.5、FRONTEND_DESIGN 9.2。

## 验证

- `dotnet test` 129/129；前端 `tsc -b`、lint 通过。
- 沙盒（桌面、iPhone 13 模拟），公司有三张单：公司自己调度台上的、公司池里的、分给调度员的。

  | 操作 | 显示的单 |
  |---|---|
  | 公司账户默认「整个公司」 | 三张都有 |
  | 选「我调度的」 | 只有公司自己调度台上的那张 |
  | 刷新页面 | 仍是「我调度的」 |
  | 切回「整个公司」 | 三张 |

  - 调度员的页面没有下拉框，只看到分给自己的那张。
  - 页面没有报错。

## 第 2 轮：选项改名

- 下拉框选项「整个公司 / 我调度的」改为「全部 / 调度」，代码注释和文档（PRD 4.5、FRONTEND_DESIGN 9.2）一起改。
- 只改文字，接口和行为不变。

## 第 3 轮：过滤选项跟着角色（全部 / 调度 / 司导）

### 需求

- 调度员在公司信息里看到自己在每家公司名下管理的订单。
- 司导看到自己在每家公司名下派给自己的订单。
- 过滤选项改为 全部 / 调度 / 司导，每个角色只能看自己管的和自己跑的，不能看别人的；选项跟着角色权限展示：司导不能看公司全部订单和调度手里的订单。

### 改动

- 后端 `GET /api/company/orders` 的 `scope`：
  - `all`：只有这家公司的公司账户。
  - `desk`：公司账户、调度员（`OrderRules.OnDesk`）。
  - `driver`：所有人，这家公司里派给自己跑的。
  - 不传用角色的第一项；不在范围里的 403（`CompanyOrderScopes.For`）。
  - 操作权限只给自己管的单：公司账户管本公司全部，调度员管自己调度台上的；只是自己跑的单 `canEdit` / `canSetShareLevel` / `canReturn` 都是 false。
- 前端：
  - `CompanyOrderRecords` 收 `scopes`（第一项是默认），不止一项时显示下拉框；
  - `CompanyPage` 按角色给：公司账户 `all/desk/driver`，调度员 `desk/driver`，司导 `driver`；
  - 记住的选项不在这个角色的范围里就用默认。
- 修了一个问题：下拉框选回当前的范围（或第一次选和默认相同的一项）时，表格会一直停在「正在加载…」。现在选的和当前一样就不动。
- 测试：
  - 公司账户 all / desk / driver；
  - 调度员默认（desk）和 driver，driver 下的单只能看；
  - 调度员请求 all 是 403；
  - 司导请求 all、desk 都是 403。
- 文档：API_CONTRACT、PRD 4.5、FRONTEND_DESIGN 9.2。

### 验证

- `dotnet test` 129/129；前端 `tsc -b`、lint 通过。
- 沙盒：甲、乙两家公司；小调度同时是两家的调度员；小司导是小调度的司导。
  - 订单：
    - 甲池里的单；
    - 甲 - 调度管的单（小调度建，小司导跑）；
    - 甲 - 公司派给小调度跑（在甲公司账户调度台上）；
    - 乙 - 调度管的单（小调度建，小司导跑）。
  - 甲公司账户：下拉框「全部 / 调度 / 司导」。
    - 全部：三张甲的单；
    - 调度：甲 - 公司派给小调度跑；
    - 司导：没有。
  - 小调度在甲：下拉框「调度 / 司导」。
    - 调度：甲 - 调度管的单；
    - 司导：甲 - 公司派给小调度跑。
  - 小调度切到乙：调度是乙 - 调度管的单，司导没有。
  - 小司导：没有下拉框。在甲看到甲 - 调度管的单，切到乙看到乙 - 调度管的单。
  - 直接请求接口：小司导要 all、desk 都是 403，小调度要 all 是 403。
