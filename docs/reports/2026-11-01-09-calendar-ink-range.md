# 透明度滑条加大调节范围

## 目标

用户反馈：日期文字的透明度拉到最低后，仍然挡住背景层里的天气。

## 原因

滑条只在一个范围内调。拉到最低时：

- 日期和派出人仍有 45% 不透明度，黑色粗体压在上面。
- 浮雕字和天气只有 62%。

两层差不多深，所以天气读不清。

## 改动

`calendarInk.tsx` 调整滑条最低一端：

- 日期和派出人（`TEXT_LOW`）：0.45 → 0.08，几乎完全淡出。
- 浮雕字和天气（`PLACE_LOW`）：0.62 → 0.7。

最高一端不变（日期 1、浮雕字 0.06）。调度台日历用同一个滑条，也跟着变化。本机已存的滑条位置不变。

## 命令结果

- `npm run build`：成功。
- `npm run lint`：29 条警告，没有新增。
- 沙盒手机视口截图，滑条分别放在最低、中间、最高：
  - 最低：「阴」「降雪8mm」「降雨25mm」清楚可读，日期和派出人只剩淡影。
  - 中间：和原来一样，两层叠在一起。
  - 最高：日期清楚，背景几乎看不见。
