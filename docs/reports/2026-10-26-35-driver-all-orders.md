# 调度台司导日历显示全部订单

## 目标

调度台点开司导时，能看到这位司导的全部订单，不限本公司。订单区仍只显示当前范围的单。

## 改动

- `GET /api/orders` 增加已有参数 `driverId`。公司和调度员只能查自己调度台上已批准的司导，返回这位司导名下的全部订单。名单规则仍用 `DriverRoster`，与 `GET /api/drivers` 同一条。
- 不带 `driverId` 时，公司仍只看本公司，调度员仍只看分给自己的单。
- 别人的单不带回备注、司导备注、游客人数、附件、行程说明和联系方式，仍带回公司名、公司订单号和日期。
- 调度台点开司导后用这份结果画未来行程。自己派出的日期仍显示本人姓名，可以拖回；其他人的日期标出所属公司，没有公司则标出订单号，不能拖走。
- 权威文档已同步：`API_CONTRACT.md`、`ARCHITECTURE.md`、`PRD.md`、`FRONTEND_DESIGN.md`、`DEVELOPMENT_PLAN.md`。

## 命令结果

- `Dispatcher_desk_lists_a_drivers_orders_from_every_company`：通过。公司订单列表看不到别家的单；带上这位司导的 `driverId` 后能看到，公司名和公司订单号都在，备注被去掉。没向该公司申请的司导返回空列表。调度员同样能看到。
- 前端 `tsc --noEmit`：通过。
- 重启 API 后打开 CC-boss 的调度台，点开 CC-boss。请求是 `GET /api/orders?driverId=...`，日历打开。这位司导没有未来行程，所以显示「暂无未来行程」。订单区仍是「暂无订单」。已关闭卡片，未退出登录。
