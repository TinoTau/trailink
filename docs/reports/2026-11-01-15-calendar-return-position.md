# 编辑当日活动后返回日历的位置

## 目标

用户要求：确认所有日历里，编辑订单某一天的活动后回到日历时，停在这张订单的日期，而不是停在半年以前（日历最早的月份）。

## 检查范围

能编辑当日活动的日历只有两处：

- 「我的行程」：当日卡片在当月下方展开，日历本身不换。
- 调度台和派给调度：订单日历里点某一天，当日卡片替换订单日历；点「返回日历」时订单日历重新挂载。

司导卡片、车辆日历点日期是打开冲突选择或车辆，不进当日编辑。

## 结果（沙盒手机视口，Playwright）

修改前：

- 调度台：返回日历后，那一天在日历滚动区外 1871 像素，也就是停在最早的月份。**有问题。**
- 我的行程：保存活动后页面不跳，新活动出现在原来表单的位置附近；收起当日卡片后日期仍在可见范围内。没有问题。

## 改动

`DispatcherPage.tsx`：

- 进入某一天的当日卡片时，记下这一天的日期。
- 返回订单日历后，把这一天滚到日历中间。
- 第一次打开订单仍然按订单第一天定位，和原来一样。

## 修改后

- 调度台：返回日历后这一天可见。
- 派给调度：返回日历后这一天可见。
- 我的行程：不变。
- 浏览器控制台没有错误。
