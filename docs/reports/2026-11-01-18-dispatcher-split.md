# 调度台组件拆分

## 目标

完成 `DEVELOPMENT_PLAN.md` 第 3 节剩下的一项：`DispatcherPage.tsx` 里全局拖拽监听和各区界面集中在一个组件，拆成拖拽控制、订单区、司导区。只整理代码，不改任何行为；不动后端和数据库。

按用户要求，第 5 节「按订单归属的数据权限」暂不做（等抢单功能设计完）。

## 改动

| 文件 | 内容 |
|---|---|
| `useBoardDrag.ts`（新） | 全局 pointer / touch 监听：鼠标移动超过阈值开始拖；触屏按住约 0.5 秒才拖、日历有订单的日期直接拖是整单；松手按落点分派（分配、按天分配、取消、绑定 / 解除车辆、排序）；没拖动算点击。拖动中的状态和悬停高亮也在这里。页面每次渲染后把要做的动作写进 `BoardDragActions` ref。 |
| `OrderPane.tsx`（新） | 订单区：订单 / 车辆切换、筛选按钮、已分配颜色色块、说明、订单图标；创建订单日历（`CreateOrderCard`）；打开的订单日历或当日卡片（`SelectedOrderCard`）。车辆区仍是 `VehicleBoard`，由页面传入。 |
| `DriverPane.tsx`（新） | 司导区：标题栏、已隐藏名单、说明、图标（置顶、拖动）、可拉高的卡片外框；`DispatcherPoolCard`（派给调度的调度员订单池）；`DriverDetailCard`（司导日历）；驾照照片的读取和管理移进 `DriverLicense`。 |
| `DispatcherPage.tsx` | 约 2130 → 1530 行。保留数据读取、分配 / 取消 / 绑定等动作、三张日历（订单、司导、车辆）的联动和定位、冲突选择、拖动标签。 |

只在一个区里用到的界面状态（说明展开、已分配颜色色块、已隐藏名单展开、驾照照片）跟着移进对应组件。

日历联动没有拆出去：订单日历、司导日历、车辆日历的滚动对齐和跳转要同时读写三张卡片，拆开反而要在组件之间来回传 ref。
