# 执行报告：司机端日历按示意改版

范围：现有 `/driver/calendar` 预览页改成白底圆点日历；日详情不再展示日期和订单号  
状态：本轮目标已完成；未进入调度员日历

## 1. 目标

按用户示意重做司机端日历观感，并去掉每日行程详情里的日期、订单号。

## 2. 对应模块与改动

1. 对应现有司机端日历，不新开页面或 API。
2. 改动：`frontend/src/pages/driver/DriverCalendarPage.tsx`、`driver-calendar.css`、`localDate.ts`；权威文档 `docs/FRONTEND_DESIGN.md`、`docs/PRD.md`。
3. 已有连续滚动日历和预览查询，在原位置改样式与详情结构。
4. 无第二事实来源；颜色仍只写 `localStorage`。
5. 不新增数据库实体。
6. 不改后端契约。API 仍返回 `orderNo` 和 `date`，前端不再渲染。

## 3. 本轮改动

- 标题改为「我的行程」；日期格改为圆角药丸；默认色为薄荷绿（已完成）/ 浅蓝（未完成）。
- 底部 Drawer 改为当月下方圆角卡片。
- 详情只显示目的地、行程描述、活动；活动时间只显示 `HH:mm`；有票活动右侧标「电子票」。
- 页面底部保留「自定义颜色」。颜色存储键改为 `trailink.driverCalendar.colors.v2`，以套用新默认色。
- 预览 API、连续滚动、无登录隔离均未改。
