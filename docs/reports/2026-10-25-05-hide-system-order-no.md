# 调度台与司导日期详情不再展示系统订单号

## 目标

调度台订单和司导日期详情头：有公司订单号就显示公司订单号，否则显示备注，都没有就空着；超过 12 字截断。系统订单号仍用于领取和公司信息。

## 对应模块

1. 现有模块：调度台订单图标/卡片、`OrderInfoEditor`。
2. 展示文案抽到 `orderFlags.orderDisplayLabel`，不另开一套订单标识。
3. 未改 API 或表。

## 验证

- 我的行程日期详情头为 `P-DRV-TEST`，不是 `TL-…`。
- 调度台所有订单：带公司订单号的显示 `P-DRV-TEST`，其余显示备注；没有 `TL-` 开头。
