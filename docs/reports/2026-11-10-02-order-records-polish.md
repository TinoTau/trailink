# 订单记录：去掉着色、选中一行、锁住背景、调整日期 2026-11-10

## 需求

- 订单记录的框体颜色和整个界面保持一致，不着色。
- 年份左对齐。
- 选中某一单给一个效果，让人知道自己正在看哪一单。
- 编辑订单时，后面的公司信息页不应该跟着滑。
- 编辑里也能重新调整日期，可以用新弹框。
- 尽量复用代码、接口和 UI。

## 改动（只改前端）

- `order-records.css`：
  - 表头改成白底灰字；年份行改成左对齐灰色小字，去掉蓝、绿底色；
  - 新增选中样式：浅灰底，第一格左边 3px 深色竖条。
- `CompanyOrderRecords.tsx`：
  - 点一行或长按一行都会选中这一行，编辑、改日期回来还在；
  - 长按操作框开着时锁住页面；
  - 提示文字跟着改。
- 背景跟着滑：
  - 原因：弹框是 fixed，但后面的页面没有锁，在弹框里滑到头或滑到弹框外面时，页面会被带着滑。
  - 新增 `useLockPageScroll`：弹框开着时 html / body `overflow: hidden`，几个弹框叠在一起时，最后一个关掉才解锁。
  - `.account-overlay`、`.account-card` 加 `overscroll-behavior: contain`。
  - 订单弹框、长按操作框、改日期弹框都用上。
- 调整日期：
  - 订单弹框日期一行右边加「调整日期」（订单 `canReschedule` 时有），打开 `OrderRescheduleDialog`。
  - 复用：
    - 调度台的订单日历卡 `DispatcherCalendarCard`；
    - 拖动手势 `useOrderReschedule`；
    - 接口 `PUT /api/orders/{id}/dates`。
  - 抽出 `orderReschedulePreview.tsx`（预览 `reschedulePreviewOf`、按钮条 `RescheduleFooter`、提示 `rescheduleHint`、保存 `saveOrderDates`）。调度台 `DispatcherPage` 改成用它，行为不变；弹框也用它。
  - 弹框打开就是改日期状态，行程放在日历中间，前后多留两三个月方便挪；要删日子时保存两步红框。
  - 保存后订单弹框和订单记录重新读取。
- 文档：FRONTEND_DESIGN 9.2。
