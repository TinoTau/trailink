# 调度台上下两张日历一起滑 2026-11-09

## 需求

调度台上下两块区域的日历同步滑动要统一：滑上半部分的日历时，下面的司导日历也跟着滑。订单和司导、车辆和司导都一样，不分情况。

## 原来的情况

- 订单日历滑动带动司导日历，反过来不带。
- 打开当日卡片时也不带。
- 车辆管理时正相反：司导日历带动车辆日历，滑车辆日历时司导日历不动。
- 创建订单日历和司导日历之间不同步。

## 改动（只改前端）

- `DispatcherPage.tsx`：
  - 新增 `topCalendarBody()`：上半部分正在显示的日历。车辆管理时是车辆日历，创建订单时是创建日历，否则是订单日历。
  - 新增 `syncCalendars(source, target)`：按 source 顶上第一个看得见的日期，把 target 里同一天对齐到同样的高度（`alignCalendarScroll`）。
    - 防抖：同步设好 target 后记下它的位置，target 因此触发的滚动事件跳过，不会反过来带动 source，两边不会来回抖。
  - 上半部分的三种日历滑动都调 `syncDriverCalendarFromTop`，司导日历滑动调 `syncTopCalendarFromDriver`。
  - 上面是当日卡片或调度员订单池（不是日历）时，自然不同步。
  - 打开创建订单时，司导日历也先对齐过来；打开订单、车辆时原来就会对齐。
  - 去掉不再用的 `selectedDriverIdRef`、`selectedOrderDayIdRef` 和 `syncVehicleCalendarFromDriver`。
- `OrderPane.tsx`：创建订单卡片接 `onBodyScroll`。
- `VehicleBoard.tsx`：车辆日历接 `onCalendarScroll`。
- 文档：FRONTEND_DESIGN 7.3、车辆一节。
