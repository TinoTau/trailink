# 车辆可用停用与直接删除

## 目标

车辆详情里用可用 / 停用选择状态。垃圾桶始终删除车辆，不再把可用车辆改成停用。

## 改动

- `VehicleWriteDto.available` 随创建和更新写入。已去掉 `POST /api/vehicles/{id}/retire`。
- 详情在车牌号上方增加可用、停用。已保存的车辆点选后立即保存；还没保存的车辆只记在表单里，随保存提交。
- 垃圾桶先套红框，再点一次调用删除。可用车辆和所有车辆都是同一套删除。
- 停用后不出现在可用车辆，仍留在所有车辆。
- 契约、PRD、前端设计、架构、开发计划和数据库契约已改成同一套说法。

## 命令结果

- `dotnet test` 过滤 `VehicleTests`，输出改到临时目录：通过 1。停用改为 `PUT` 写入 `available=false`，再删除。原有 CS8604 警告仍在，测试通过。
- 已停掉旧 API 进程，Debug 构建成功，重新在 `http://localhost:5168` 启动。
- 浏览器（公司账户调度台）：添加车辆时能看到可用、停用。保存车牌「验B0002」后出现在可用车辆。点停用后可用车辆为空，所有车辆里仍有这辆车，详情写着停用。垃圾桶先变成「确认删除车辆」，再点后列表为空。数据库里没有「验B0002」。调度台已回到订单页。
