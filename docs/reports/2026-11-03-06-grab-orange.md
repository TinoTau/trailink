# 抢单界面收色，橙色标出抢单日期

## 需求

- 抢单页颜色太多，控制在三种以内，保留橙色作为抢单专用色。
- 司导从抢单页跳到我的行程时，用橙色标出这张单的日期；和已有行程冲突也要显示橙色虚线框。
- 调度台点待确认的抢单时，订单日历和司导日历都用橙色标出日期。

## 改动（只改前端）

- 抢单页 `grab.css`：黑白灰 + 橙色（抢单）+ 红色（冲突）。等级标签改灰；「抢这 N 天」橙色描边、确认时实心橙；已抢提示改浅橙；筛选选中改深灰。
- 抢单页 `GrabPage.tsx`：日期标题、「去处理」、顶部「在我的行程里看」都跳到 `/driver/calendar?date=…&grab=日期,…`。
- 我的行程 `DriverCalendarPage.tsx`：读 `grab` 参数，这些日期画橙色虚线框（独立的一层，盖在行程颜色和冲突红色之上）；日历上方一行说明和「不再标出」。
- 调度台：
  - `CalendarMark` 加 `grab`（橙框）和 `inert`（只做标记，不能点、不能拖）。
  - 订单日历：有人抢时，未派的日期改浅橙底、橙框、写「抢单」。
  - 司导日历：抢单司导的日历标出他抢的那张单的日期；空日期补只做标记的格子，已有行程的那天在原格子加橙框。
  - 抢单相关的颜色统一成同一种橙色：有人抢的订单图标、抢单司导图标虚线框，「抢单待确认」文字，确认派单按钮。
- FRONTEND_DESIGN 抢单页、调度台抢单两处更新。

## 验证

- `tsc -b`、`npm run build` 通过。
- 沙盒界面（司导手机 390 宽、调度员桌面 1366 宽）：两张公开单，一张和司导已有行程冲突。
  - 冲突单点「去处理」→ `/driver/calendar?date=11-12&grab=11-12,11-13`，两天都有橙色虚线框，12 日是已有行程也照样标出。
  - 司导抢另一张单后，调度员点这张单：订单日历 8、9、10 日标「抢单」橙框；司导日历同样 3 天橙框，司导自己 12 日的行程照常。页面无报错。
