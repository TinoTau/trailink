# Trailink V1 前端设计说明

版本：V1 MVP 第一阶段  
日期：2026-10-23（2026-11-01 按页面和功能拆分小节，交互不变）  
状态：当前界面基线

本文写界面和交互。业务规则（谁能做什么）以 `PRD.md` 为准。不引入第三方日历组件、地图或路线编辑器。

---

## 1. 页面与路由

| 路由 | 页面 | 谁能打开 |
|------|------|----------|
| `/login` | 登录 / 注册（司导或公司注册，调度员由批准产生） | 未登录 |
| `/driver/calendar` | 我的行程：本人的行程日历 | 全部角色 |
| `/dispatcher` | 调度台 | 公司、调度员 |
| `/company/assign` | 派给调度：复用调度台页面，右侧是本公司调度员 | 仅公司 |
| `/company` | 公司信息 | 全部角色 |
| `/me` | 个人信息 | 全部角色 |

- 路由、菜单和角色准入只在 `frontend/src/navigation.ts` 定义。
- 电脑网页（宽度 ≥ 900px）：版式和手机一致，只限制会被拉变形的部分。调度台的卡片（订单、司导、车辆、改日期）最宽 720px 居中，外面的方块区照旧铺满；「我的行程」日历最宽 720px 居中，滚动条仍在窗口右边；公司信息、个人信息正文最宽 800px（订单记录表格不用左右滑）。不然 1366 宽时日历每格会被拉到约 190×36。
- 接口类型从后端 OpenAPI 生成到 `frontend/src/api/generated/`；`types.ts` 不手写后端 DTO，只放别名、响应归一化和纯 UI 模型。
- 不提供 `/orders` 表格页或 `/orders/:orderId` 编辑页。进行中的单在调度台，公司信息里有全部订单的订单记录，本人行程在 `/driver/calendar`。旧地址重定向到角色首页。行程天数取接口返回的 `dayCount`。
- 公司登录后进入调度台，司导登录后进入我的行程。

## 2. 全局约定

### 2.1 页面外观与菜单

- 调度台、我的行程、公司信息、个人信息都是独立白底页，不使用 Ant Design 顶栏。风格：白底、圆角大图标、底部色点改色。
- 右上角「我的行程」单独成按钮；旁边三点图标展开下拉：派给调度（仅公司）、调度台、公司信息、个人信息、退出。
  - 当前页不出现在下拉里；司导看不到调度台；已在行程页时不再重复「我的行程」。
  - 页面自己的操作（行程管理、创建订单）留在外面。
- 文案使用简体中文。

### 2.2 数据刷新

- 进入调度台、派给调度、我的行程、公司信息或个人信息时，重新读取这一页的数据。
- 从其他窗口回到当前页也会再读一次。
- 已经改过、还没保存的输入保持不动。

### 2.3 手机与触屏

- 视口固定为设备宽度和 1 倍缩放，键盘弹出时不改变页面尺寸。
- 输入框在窄屏和触屏上用 16px，避免浏览器聚焦时整页放大。点进订单编辑时页面不放大，仍按屏幕高度拉伸。
- **保存按钮的位置**：所有创建、修改的「保存」（或「添加」「生成订单」等主按钮）都在卡片 / 弹框头上、紧挨在关闭按钮左边，同一行。
  - 订单信息编辑区（`OrderInfoFields`）的「保存」画到卡片头的空位里（`SaveSlotContext` / `SaveSlot`，卡片头 `card-head-actions` 里关闭按钮左边）：调度台订单卡、司导卡片备注、车辆卡（添加 / 编辑车辆）、当日卡片、我的行程订单信息、公司信息订单弹框都一样；不在卡片里时才画在「订单信息」标题那一行。
  - 创建订单卡：框选日期后头上出现蓝色实心按钮，写出起止日期「添加 11月15日–11月17日」（`card-primary`，和司导界面框选日期后的「添加 … 仅日期」同一种蓝色按钮；「仅日期」写在底部说明里，按钮短一些，手机上标题不被挤成竖排）。卡片头不再写拖选说明，说明只在底部。改日期（调度台和公司信息的改日期弹框）：头上「保存」（`RescheduleSaveButton`，要删日子时两步红框），底部是说明和取消 / 还原。AI 建单：头上「生成订单（n 天）」，底部「重新上传」。
  - 活动库弹框：添加 / 编辑活动的「保存」/「添加到活动库」、活动评价的「保存评价」、选活动的「添加 n 项」都在头上「关闭」/「取消」左边；删除类按钮留在底部。
  - 行内的「保存」（个人信息、公司资料各字段后面）和当日行程里活动的「保存 / 取消」不变：那里没有关闭按钮，「保存」已经在「取消」左边。
- 登录、调度台、派给调度、我的行程、公司信息、个人信息：长按输入框以外的地方不选择文字，也不弹出系统菜单。界面里已有的长按操作照常（例如按住约 0.5 秒拖选日期）。输入框、文本域和下拉框仍可选中文字。
- 二次确认（红框）进行中，点页面上任何别的地方都取消红框（`useDisarmOnOutside`，在捕获阶段监听按下，卡片、日历里拦住冒泡的按下也照样取消）：订单退回 / 删除、隐藏司导 / 调度员、解除绑定、车辆删除和停用、我的行程解除这一天、活动库删除活动、抢单确认、改日期删掉日子。
- 页面高度用 `100dvh`，前面先写 `100vh` 兜底（iOS 15.4 以前、旧版安卓浏览器不认 dvh）。
- `viewport-fit=cover`：调度台、我的行程、公司信息 / 个人信息的页面容器左右和底部留出 `env(safe-area-inset-*)`，刘海屏横屏和底部横条不压内容。
- 点按目标：图标按钮 44×44（见 7.3）。
- 适配检查（2026-11-08，Chromium 按机型模拟，竖屏为主，另有两款横屏）：iPhone SE（320 宽）、SE 3、12 mini、13、15 Pro、16 Pro Max、Galaxy S III、S9+、S24、A55、Pixel 5、7、8 Pro，以及 iPhone 15 Pro、Pixel 7 横屏。每款检查：无横向滚动；图标按钮不小于 44；按钮不出屏；输入框不小于 16px；改日期和退回公司的红框两步；长按约 0.5 秒拖订单到司导（四款）。模拟用的是 Chromium 内核，iPhone 上的 Safari（WebKit）没有真机测，上线前请用真机过一遍。

### 2.4 通用操作手势

- **触屏拖动前按住约 0.5 秒**：订单图标、司导图标、调度员图标、车辆图标、排序都是这样。未满 0.5 秒时上下滑动仍滚动对应区域。鼠标按下即可拖。
- **拖动把手**：带 ⋮⋮ 把手的列表（活动选择框、已选活动、当日活动），按住把手立即拖动，把手这一小块不滚动页面；手指在把手以外的地方是滚动，长按约 0.5 秒才拖动。同一次手指移动只和经过的那一项交换一次，避免来回跳。
- **卡片头**：只有能拖动的卡片头（调度台拖订单、拉高司导 / 车辆卡片）按住时不滚动页面；不能拖动的卡片头（例如我的行程当日详情里的订单号一行）按住空白处仍可上下滑动。
- **卡片里编辑订单信息 / 备注**：调度台和派给调度的订单卡片、司导卡片，点笔记图标后卡片里只显示编辑内容（订单号、公司、备注、截图等），不在下面接着显示日历，往下滑到编辑内容末尾为止；再点一次收起，日历回到打开编辑前的位置。
- **抢单范围**：调度台（含派给调度）订单卡片点编辑后，日期天数下方一行三个互斥按钮：调度自留、公司内部、面向所有人，样式同当日详情的住宿位置按钮（`place-mark-bar`）。只给这张单的调度员和所属公司的公司账户显示；点了立即保存；再点已选的不变。没绑公司时后两个按钮置灰，下面提示「绑定所属公司后，才能放给公司内部或所有人」。
- **抢单（调度台）**：
  - 放出去的单（公司内部、面向所有人，且还有未派日期；派给调度里是还没分给调度员）订单图标用虚线边框，调度台和派给调度一样。
  - 有人抢：图标第四行橙色「抢单待确认」，几个人抢写「N 人抢单待确认」，并且右上角红角（同普通冲突单）。
  - 司导区：抢单司导排在置顶之后、其余之前，图标虚线边框；不在名单里的陌生人也显示（确认后自动进名单）。
  - 点抢单司导：打开他的司导卡片，同时打开他抢的订单。点有人抢的订单：一人抢时同时打开这位司导；多人抢时弹出选择框（重复日期框的样式，每格扑克牌底、写司导名），司导区滚到这几位，图标换成同样的扑克牌；点选择框或司导图标都打开那位司导。
  - 有人抢的订单图标和抢单司导图标用橙色虚线框（只是放出去、还没人抢的单仍是灰色虚线框）。
  - 打开有人抢的订单：订单日历上被抢的（还没派的）日期浅橙底、橙色虚线框、写「抢单」；司导卡片打开的是抢单司导时，他的日历也用同样的橙框标出这些日期，原本空着的日期只做标记，不能点也不能拖，已有行程的那天在原来的格子上加橙框（确认时会被拒）。
  - 订单卡片日期天数下方、司导卡片备注下方是橙色确认条：「某某 抢单待确认」/「抢了 订单名，待确认」和「确认派单」按钮。多人抢还没选人时，订单卡片的确认条只提示去选。
- **司导卡片备注**：点「保存」成功后收起编辑，回到司导详情（日历）；失焦自动保存不收起。
- **两步确认**：解除、删除、停用这类操作，第一次点击只给按钮（或日期）套上红框，再点一次才执行，不弹框。点到别处取消红框。
- **点空白处关闭**：订单、司导、车辆、调度员详情，点弹框外没有按钮的空白处关闭；点按钮仍执行按钮自己的操作。

### 2.5 照片查看（车辆照片、驾照照片共用）

- 小图点开后看大图，大图按横向比例固定展示，竖图也缩到这个高度，切换时大小不变。
- 下方一条横杠对应一张照片，长短相同，当前这张更深。左右滑动换一张。
- 可下载；有权限时可删除（两步确认）和更新。
- 点详情框里照片和按钮以外的空白处关闭大图。
- 上传前在页面里压成 jpg，最长边 1600，不把原图发给服务器。压缩只在后台线程里做，浏览器不支持时直接报错，不退回主线程；超过 20 秒停掉并提示换一张小一些的照片。正在处理的那一格转圈，其他格不受影响。项目默认在手机浏览器上使用。

## 3. 订单信息卡（`OrderInfoPanel` / `OrderInfoFields`）

调度台订单卡、我的行程当日卡、公司信息订单弹框共用这一套，保存走 `updateOrderInfo` → `PUT /api/orders/{id}`。

- **显示名**：由后端给出（`label`），前端只截断。卡片头、公司信息订单图标和卡片、领取成功提示、取消行程和冲突提示都不展示系统订单号。有公司订单号用公司订单号，否则用共用备注，都没有就空着，超过 12 字截断。领取框只提示输入公司订单号。
- **调度台和派给调度的订单图标**（同一个 `orderTileLabel`，拖动时的小标签也一样）：有公司订单号写订单号；没有时依次写人数、车型、共用备注第一行，例如「2人 五座车 基督城-特卡波-库克山…」，图标里最多两行，多的省略。这些都没有时写后端的显示名（看不到详情的单），再没有就只显示日期。
- **卡片头**：名字旁蓝色笔记图标打开编辑，编辑项在卡片可滚动区域里，手机上可以滑到公司、订单号、备注和截图。收起时备注显示在订单号之下、日期信息之上。
- **人数、车型、南/北岛**（`basics`，`OrderBasicsFields`）：调度台订单卡和公司信息订单弹框里有，司导没有。人数和车型都是下拉框（`ChoiceField`）：人数「— / 2 / 3 / 4 / 5 / 6 / …」，车型「— / 5座 / 7座 / 12座 / …」；选「…」换成输入框直接打字（人数只收数字，车型最多 50 字），输入框右边的小箭头回到下拉框；已有的值不在选项里（如「1」「7座阿尔法」）时打开就是输入框；「—」是不填（人数为 0）。南/北岛不是主要信息，三样排在同一行，南/北岛只是一个小按钮（`IslandToggle`），按一下换一个：南岛 → 北岛 → 南北岛 → 南岛，没填时显示南岛。和其他订单信息一起点「保存」。
- **调度台可改**：所属公司、公司订单号、自己的调度备注 `notes`（`order_notes`，互不可见），上传订单截图。保存后回到日历。
- **我的行程可改**：司导备注 `driverNotes` 和订单截图，不能改公司订单号。点开某一天时，公司订单号下面显示当天调度员的姓名和联系方式。
- **共用备注** `sharedNotes`：三方都能看、都能改，排在各自备注上方。
- 没有内容时备注输入框只有一行，有内容再跟着增高。
- **所属公司**：调度员搜索公司名称，点选后立即用 `PUT /api/orders/{id}` 写入 `companyId`，不必再点保存。公司账户看所属公司只读。

## 4. 当日行程（`DriverDayEditor`）

点击某一天打开独立的当日行程卡片，不和订单信息编辑叠在同一张卡里。

- **住宿位置**（写入 `endLocation`）：一行按钮 基、凯、特、瓦、皇、蒂、但（读 `GET /api/places`），或输入其他地点。再点一次已选中的按钮就清空，当天不再显示浮雕字。
- **当天车辆**（只在我的行程）：住宿位置按钮下方，若这一天已绑车，同一行紧凑显示车牌和型号（`vehicles.info`），下一行显示车辆共用备注。没有绑车不显示。
- **活动**：可新增、修改、删除、拖动排序（写入 `sort_order`）。字段：活动内容、承办方、预订时间、签到时间、电子票。电子票上传后可打开查看。
  - 「添加活动」弹出活动选择框（`pages/library/ActivityPicker`，底部弹出）：
    - 按住宿位置列出当地活动库活动，显示评分。
    - 列表顺序：先按本人拖出来的顺序，其余按评分。按住 ⋮⋮ 或长按约 0.5 秒拖动调整，松手后保存到账户（按目的地分开）。
    - 点选多选，圆圈里标出点选先后；选中的同时放进下方「已选」。
    - 「已选」是这一次要添加的顺序：按住 ⋮⋮ 或长按拖动调整，× 移除。确认后按「已选」的顺序加到这一天已有活动后面。
    - 顶部搜索整个活动库；「手动填写」打开原来的填写表单。
  - 已添加的活动紧凑两行：第一行是 ⋮⋮ 把手和活动名（有承办方、时间时在名字下面小字）；第二行是右对齐的小按钮：评价（只有活动库来的才有）、编辑（承办方、时间）、上传电子票、删除（红字）。
  - 按住 ⋮⋮ 立即拖动排序，或在活动其他位置长按约 0.5 秒后拖动（`useHoldReorder`）。按住前手指移动是滚动页面；拖动结束后吞掉紧跟的点击。
  - 评价框（`ActivityReview`）：活动名、英文名、目的地、平均分、共用备注、图片；我的 1–5 星和评价文字；所有人的评价。
- 日期提交 `YYYY-MM-DD`。预订 / 签到时间提交 `YYYY-MM-DDTHH:mm:ss`，禁止使用 `toISOString()` 或带时区偏移的字符串。
- 订单最后一天起满 7 天后，电子票和订单截图不再提供查看，头像仍在。

## 5. 日历通用

调度台的订单、司导、车辆、创建订单日历和我的行程日历共用以下规则。

- **范围**：月份上下连续滚动，不切换单月。从半年前画到半年后，含当前月共十三个月。已有行程更早或更晚时仍画出来。
- **今天**：浅灰细边框标出，不另加色块或加粗数字。
- **有行程的日期**：圆角方格填充；空白日期只显示数字。
  - 订单第一天沿格子左缘、最后一天沿格子右缘用加深的填充色描边，两边不相接，单日订单也不会连成整圈。
- **日期文字**（`CalendarDayCaption`）：数字下显示分配人姓名（优先 `assignedByName`，否则 `createdByName`）。我的行程再加上订单所属公司：公司名和调度员名连写，超过 6 个字且本人写了公司简称时，改成「简称-调度员名」。
- **颜色**：
  - 我的行程、调度台司导详情：早于今天用「已完成」色，今天和之后用「未完成」色。默认薄荷绿 / 浅蓝，由页面右下角「已完成」「未完成」两个按钮改色，存在 `localStorage` 的 `trailink.driverCalendar.colors.v2`。月份标题旁不重复图例。
  - 调度台订单日历：已派日期用「已分配颜色」，未派日期用另一种颜色。
- **住宿位置浮雕**：写了住宿位置的日期叠该地点第一个字，半透明。
  - 调度台司导详情日历和我的行程日历有一条竖向滑条（`calendarInk`），固定在屏幕上（挂在 body 下，不跟卡片滚动），滑条本身 75% 透明度。只在司导卡片 / 我的行程日历显示时出现。
  - 上下拖调节：向上日期文字更明显、浮雕更淡，向下相反。触屏按下即可上下拖。
  - 滑条只影响有浮雕字的日期：日期和派出人在 8%–100% 之间变化，浮雕字和天气在 70%–6% 之间变化。没有浮雕字的日期（空白日期、没写住宿位置的日期）始终清楚，用来认时间。
  - 位置：屏幕左侧或右侧的上、中、下，一共 6 格（上 = 离屏幕顶 84px 让开标题和按钮，中 = 屏幕垂直居中，下 = 离底 24px；都加安全区）。默认右中。
  - 移动：按住约 0.5 秒（滑条稍微放大、手机轻震）再往任何方向拖，或鼠标按下横着拖，滑条跟着手指走；松手按屏幕中线定左右、按屏幕高度三等分定上中下，停到那一格。位置记在本机（`trailink.calendar.inkSide`、`trailink.calendar.inkLevel`）。键盘：左右键换侧，Shift+上下键换上中下。
  - 点一下滑条不会关掉调度台的卡片（点空白处关卡片时排除 `.calendar-ink-bar`）。
  - 透明度存 `trailink.calendar.inkBalance`（没有记录时停在正中），左右位置存 `trailink.calendar.inkSide`。
  - **车牌挡（只在我的行程）**：控制条最上面多一挡。原来的整段（浮雕 → 日期和公司）压在条的下面 80%，刻度线以上是车牌挡；点或拖过刻度和顶端的中点就进这一挡，滑块吸到顶、变蓝。这一挡日期文字和最上面一样清楚，日期下面写这一天配的车牌（`vehiclePlate`，同一天多张单配了不同的车用「/」连起来），没配车只显示日期。往下点或拖就回到原来的整段。记在 `trailink.calendar.inkPlate`。调度台的控制条没有这一挡。
  - 调度台：订单卡片没有滑条，但和司导卡片共用同一份透明度（`DispatcherPage` 里一个 `useCalendarInk`，订单卡片 `inkFollow`），拖司导卡片的滑条时，打开着的订单日历的日期文字和浮雕字一起变。
- **冲突日期**（同一司导同一天多张单，`ConflictDatePopover`）：
  - 填成红色。点该日期，在原位置弹出多个同日按钮，并关闭已经打开的订单详情。
  - 调度台：每个按钮一个居中的镂空图案对应一张订单，画成固定大小的正方形，外圈比中间文字更大，中间留空，不压住文字，不随按钮拉宽或拉高，不平铺；梅花中心同样镂空。图案按全部冲突订单固定排序，换日期也不变。前四种是扑克牌黑桃、红心、方块、梅花，第五张起用麻将牌图案。对应订单图标同时换成同样的图案。
  - 调度台按钮文字：自己派出的第一行是日期，第二行与我的行程日期格同一套文字；不是当前调度员派出、无权移除的不显示文字。
  - 我的行程：按钮不画图案，第二行与普通日期格一样显示调度员名字，按各订单自己的起始日期从早到晚排列。
  - 点一个按钮先套红框，再点一次才 `PUT` 这一天 `driverId: null`，按拆单处理。卡片保持打开。
- **框选日期建单**（我的行程「行程管理」和调度台「创建订单」共用）：
  - 鼠标按下即拖选。苹果和安卓触屏按住不动约 0.5 秒后才开始拖选，未满时滑动仍滚动页面，点一下只选中当天。
  - 范围跟着手指下的日期扩展，拖到上下边缘时日历跟着滚动，当前选到的日期留在可视区域里。
  - 一次最多三个月：结束日可以落到开始日三个月后的同一天，月底没有这一天时落到该月最后一天。
  - 走共用的 `createOrderWithDays`（内部是 `POST /api/orders` + 逐日 `POST /api/orders/{orderId}/days`）。前端不封装 `claim` / `range` 客户端。

## 6. 我的行程（`/driver/calendar`）

- 标题「我的行程」。默认停在当前月并尽量露出今天。七列周一至周日。
- 只显示登录用户本人 `driver_id` 的日期，已结束的单也留在对应日期上，用「已完成」色。页面数据只读 `GET /api/orders`，不拉司导列表，不切换他人；不把前端 `driverId` 当作登录身份。
- **当日卡片**：点击有行程的日期，在当月日历下方展开圆角卡片，头部是订单信息卡（第 3 节），下面是已添加活动和一套「添加活动」（第 4 节）。同一天有空行程时不另画添加按钮。再点同一天收起。
  - 卡片落在可视区域下方时，点开的日期旁出现「详情」向下箭头，放不下就停在日历可视区域底部，点一下滚到卡片；卡片顶部已经露出来时不显示。
  - 同一订单还有其他人分担时，提示拆分。
- **行程管理**（右上角下拉）：
  - 订单号和输入框同一行，「领取」与「取消行程」并排。取消行程文字在按钮内居中，按钮高度和字号不变，预先留出确认按钮高度，拖选时不因按钮出现而挤走日历。
  - **领取**：输入公司订单号，调用 `PUT /api/orders/{orderId}/driver`。成功后日历跳到该单首日并展开当日卡片。
  - **框选建单**：见第 5 节，写当前用户 `driverId`，不写 `companyId`。
  - **取消行程**：点「取消行程」后点击某天，只解除本人在该单上的日期（`PUT` 当日 `driverId: null`），其他司导的日期不受影响。由有效点击或键盘 Enter / Space 触发，滑动日历不解除。
- **取消某一天**：点开某一天后，备注图标右侧的垃圾桶先把这一天套上红框，再点一次该日期才解除当天这一条，同样 `PUT` `driverId: null`。其余日期不动，订单成为拆单，调度台未分配重新列出这张单。
- 日历格子上不显示车牌。
- **天气**：后端给出天气的日期（地点规则见 PRD 第 8 节），天气和浮雕字一起放在背景层（`calendar-day-backdrop`）：浮雕字缩小贴格子上沿，天气（`calendar-day-weather`）贴下沿，透明度和浮雕字同一个变量，跟着滑条一起变；日期和派出人的位置不变，照常叠在上面。页面底部左侧注明数据来源（「天气数据：MET Norway」等，读 `GET /api/weather/source`；没有配置天气时不显示）。天气文字照后端给的显示，不做转换。调度台的日历（订单卡、司导卡、车辆卡、改日期弹框）也显示天气：同一个 `CalendarDayCaption`，日历格子的 `weather` 取行程日返回的 `weather`；来源写在调度台页头副标题后面（「调度台 · 天气数据：…」，派给调度不显示）。

## 7. 调度台（`/dispatcher`）

### 7.1 布局

- 左上角是当前登录用户姓名（派给调度是本公司名称），读登录身份。
- 上半区订单（或车辆），下半区司导。
- 订单区用同一行标签切换「订单 / 车辆」，两个标签不换行；标签下面才是当前页的操作按钮。派给调度没有车辆标签。
  - 订单：「创建订单」「未分配订单」「所有订单」；「已分配颜色」只在「所有订单」时出现。
  - 车辆：「添加车辆」「可用车辆」「所有车辆」。控件同一套 `dispatcher-chip`。
- 订单区和司导区的长说明默认收起，用下箭头展开，展开后改为上箭头收起。
- 订单列表和车辆列表分开请求，车辆失败不清空订单。

### 7.2 订单列表

- **未分配**：全部未派、拆单后仍有空日期的订单，以及同一司导日期重叠的冲突订单（即使日期都已派完），不论结束日是否已过。
- **所有订单**：有行程日、且尚未成为历史单（已派完且结束日早于今天）的订单。
- 排序：进行中订单排最前，再按出发日期靠近今天排序。未完成 = 结束日期尚未早于今天。
- **图标颜色**：
  - 整单已派：「已分配颜色」背景。颜色读当前用户 `assignedColor`，点选走 `PUT /api/auth/assigned-color`，每人一条，不写本机。改色方式与我的行程「已完成 / 未完成」相同。
  - 拆单或只派了部分日期：图标本体保持白底，右上角用直线切开一块已分配色，不按天数比例上色，并显示「拆分」。
  - 同一司导有重叠日期的订单：同样的切角，颜色为红色。

### 7.3 订单卡片

- 点击订单图标，在订单区弹出覆盖该区的日历卡片，头部是订单信息卡（第 3 节）。
- 已派给司导的订单同时打开该司导的行程，并滚到这张订单里该司导的日期。派给调度同一个规则：已分给调度员的订单同时打开这位调度员的卡片（订单列表）。拆单时打开第一个已派日期所属的司导；第一个已派日期早于今天时，滚到该司导在这张单上今天或之后的第一天。没有派司导的只打开订单卡片。
- 删除按钮是简笔垃圾桶，在编辑按钮右侧，样式和间距与司导卡移除一致。和司导、车辆一样不弹框：第一次点套红框，再点一次才执行，点别处取消。删除图标是红圈红 ×（`DeleteIcon`，原来的垃圾桶缩小后不好认），红框是按钮外面一圈；「退回公司」只把边框和文字变红，不往外扩。走同一 `DELETE /api/orders/{id}`：
  - 按界面不按角色。调度台 + 已绑公司（调度员和公司账户一样）：不用垃圾桶，直接显示文字按钮「退回公司」，确认后只解绑并退回公司池（`DELETE ?release=true`）。
  - 调度台 + 未绑公司：「删除订单」，确认后真正删掉。
  - 派给调度：始终是「删除订单」，真删。
- 调度台的订单列表用 `GET /api/orders?desk=true`，公司账户也只看自己调度台上的单；在调度台建单和 AI 建单带 `onMyDesk`。
- 图标按钮 `dispatcher-icon-btn`（编辑、关闭 ×、置顶）44×44、图标 28px；删除（`.danger`，红圈红 ×）按钮 30×30、图标 24px。大按钮上下用负边距抵掉多出的高度，标题行不变高；头像角上的置顶贴角放。AI 建单里移除文件和活动的 ×、活动库里移除标签 / 图片 / 已选活动的 × 也放大到 36–44px。
- 编辑订单信息时，抢单范围下方是「行程日期」一行和「在日历上拖动改日期」按钮（订单响应 `canReschedule` 为真才显示）。点了以后收起编辑，进入改日期：司导区收起（`.dispatcher-page.rescheduling`），订单日历变成可拖（`useOrderReschedule`，跟随滚动和创建订单的框选同一套），副标题写拖法说明（长按满 0.5 秒后换成「拉长缩短」的说明）；日历上画的是预览（平移后的各天照原样着色，新增的空白日标「新增」，用新建订单框选时的浅蓝底蓝字（`#e6f4ff` / `#1677ff`），落到范围外的不画）；拖法不用切换：按住行程里任意一天直接拖是整段平移，长按开头或末尾那天约 0.5 秒再拖是拉长缩短（没等够就拖仍是平移；改日期时行程上的格子 `touch-action: none`）；底部操作条：一行摘要（要删掉日子时变红），「取消」「还原」「保存」。要删掉日子时「保存」两步（红框）。换了订单就退出改日期。
- 点击某一天打开独立的当日行程卡片（第 4 节）。调度台上这一天已派司导、而司导区打开的不是他（拆单时每天可能是不同的司导）时，这一下只打开这位司导的卡片、日历跳到这一天，不进当日行程；再点一次才进当日行程。已隐藏的司导不打开，直接进当日行程。打开司导时订单日历看得见这一天就不动，司导日历把这一天放到和订单日历同样的高度（看不全时退一步放进可见范围）。订单、司导、车辆日历之间的同步滚动也按顶上第一个看得见的日期对齐（`alignCalendarScroll` / `alignCalendarToDate`），不再按月份对齐（各日历月份标题、表头高度不同会错开一行）。
- **上下两张日历一起滑**：上半部分的日历（订单日历、创建订单日历、车辆日历）和下面的司导日历同时打开时，滑哪一张，另一张就把同一天对齐到同样的高度，双向、不分情况（`DispatcherPage` 的 `syncCalendars`）。由同步引起的滚动不会再反过来带动另一边（记下设成的位置，自己的滚动事件跳过），所以不会来回抖。上面换成当日卡片或派给调度的调度员订单池（不是日历）时不同步。打开订单或创建订单时，司导日历先对齐过来。司导卡会画出当前打开订单覆盖的月份，即使该司导当月没有行程。

### 7.4 司导卡片

- 点击司导图标，在司导区弹出覆盖该区的行程卡片，画出这位司导的全部行程，包括已完成日期和进行中订单已过去的日期，不限本公司。着色同我的行程。
- 打开时：订单日历未打开则滚到今天；订单日历已打开时，订单日历保持原位，司导日历滚到订单日历当前的日期位置。
- 姓名下显示该司导自己填写的联系方式。
- **卡片高度**：顶部横条和标题栏可以向上拖，卡片跟着变高，最多盖住整个订单区；松手停在当前位置，往下拖回到下半区。点自己分配的日期或冲突日期时，卡片用一段短动画收回下半区，让订单区露出来。关掉后高度恢复。
- **日期**：
  - 自己分配的日期：与我的行程日期格同一套文字；点一下在订单区打开这张订单；可以拖回订单区取消。
  - 其他人分配的日期：只着色，不写公司名或调度员姓名；不能点开，不能拖动或移除，点一下只提示，触屏仍可滑动。有住宿位置时只叠地点第一个字。
- 卡片备注按钮是名字右侧蓝色简笔图标；移除按钮在备注按钮右侧并留间距，避免误触。

### 7.5 拖拽派单

- **整单派给司导**：拖动订单卡片或订单图标到司导图标；司导卡片已打开时，拖到司导区域即分给该司导。调用 `PUT /api/orders/{orderId}/driver`，日期重叠也写入。
- **按天派给司导**：从订单日历拖某一天到司导，调用 `PUT /api/orders/{orderId}/days/{dayId}`，只改该日 `driverId`。
- **派单只从订单区拖下来**：从司导卡片（派给调度时是调度员订单池）拖起的订单或日期，只能拖回订单区取消（车辆管理时是解绑车辆）。放回司导区、拖到别的司导或调度员都不派单，司导区也不亮。这样误触不会把拆单整单派给一位司导、清掉另一位司导的日期。
- 订单 / 司导详情日历里的触屏规则：没有订单的日期直接拖动是滚动；有订单的日期直接拖动是整单；按住约 0.5 秒再拖是这一天。鼠标拖某一天只改那一天。
- **从司导卡片拖回订单区（取消）**：
  - 只有自己分配的日期能拖。整单里任一已派日不是当前调度员派的，整单不会被拖起。
  - 鼠标：拆单只把当天 `driverId` 置空；未拆单（整单都是这位司导且同一人派出）调用 `PUT /api/orders/{orderId}/driver` 清空整单。
  - 触屏：直接拖清空整单，按住约 0.5 秒再拖只清空当天。
  - 不关闭卡片。拆单判定与当日编辑器共用 `isSplitOrder`。
- 不新建订单。

### 7.6 创建订单

- 「创建订单」在未分配左侧，打开覆盖订单区的日历卡片，打开时停在今天。
- 框选规则见第 5 节。确认按钮在卡片右下角。
- 不写 `driverId`，也不默认写 `companyId`；新单出现在未分配，所属公司须事后搜索绑定。

### 7.6b AI 建单（`AiOrderCard.tsx`）

- 「AI 建单」在「创建订单」右边，服务器没配 AI 密钥时不显示。打开后盖住整个调度台（最宽 760px），和创建订单互斥。
- 第一步：点选、拖入行程图和电子票（最多 12 个），也可以在卡片里直接粘贴截图（存成「粘贴的截图-时间.png」）；列出文件名和大小，可逐个移除。
  - 下面「或者粘贴行程文字」文字框（最多 2 万字），样子和上面的上传框一样（灰底、虚线框、圆角 12px，标题加深），点进去变蓝：把微信、邮件里的行程直接粘贴进来，可以单独用，也可以和文件一起识别。手机上文字框用 16px。
  - 「开始识别」：有文件或文字时才能点，按钮写明「（2 个文件）」「（粘贴的文字）」「（1 个文件 + 文字）」。
- 识别中显示转圈和「长图大约要 10～30 秒」。失败回到第一步并显示原因。
- 核对（全部展开，按手机紧凑设计）：
  - 所有内容平时都是小字文字，点一下才变成输入框，离开或回车保存（`InlineText`）。手机上只有正在编辑的那一个输入框用 16px（避免整页放大），其他保持小字。
  - 副标题一行：「N 天，导入 M 天 · 黄色待核对 · 点文字修改」。AI 提醒收成一行（「AI 提醒 3 条 ▸」+ 第一条），点开看全部。
  - 订单号、人数、车型、南/北岛、备注放在一块浅灰底里。车型没识别出来时标黄；南/北岛同一个小按钮（按一下换一个）；识别不出时显示南岛，导入时也按南岛写入。
  - 每天之间用细线分隔，不再套卡片。第一行：勾选框、日期（「11月20日 周五」，点它弹出日期选择）、「+ 活动」、右侧「住 xx」。下面缩进一格：行程文字、活动。没勾的天只占一行：划掉的日期和原因。
  - 活动一行：「酒店」/ 绿色「库」标签、名称、「签 10:40」「始 11:00」、电子票小标签（「+票」/「票」，点开选文件；只在上传了 PDF 或已配票时出现）、删除。酒店只有名称。新加的活动直接进入编辑名称。
  - 时间是 24 小时制，可输 1530、15:30、15.30、9:5，输错退回原值，清空就是没有时间。
  - AI 拿不准的地方黄底。悬停底色只在有鼠标的设备上出现。
  - 手机上卡片铺满整屏、去掉外框和圆角，底部按钮留出安全区。
  - 改了某天的日期，那天活动的时间跟着换到新日期。底部固定「重新上传」和「生成订单（N 天）」。核对中关闭要确认。
- 生成后关闭卡片、刷新订单，并打开新订单。

### 7.7 司导名单

- 司导图标只来自已向当前登录账户申请并批准的人（含本人）。公司账户只看到向公司账户申请并批准的人。
- 圆圈显示该司导上传的头像，没有头像则显示姓名第一个字。圆圈下方优先显示当前调度员自己给他写的备注（`driver_notes`，接口仍用 `notes`），没有才显示姓名；超过 12 字截断。卡片标题、恢复隐藏仍用姓名。
- 编辑司导备注时，能看到这位司导的驾照正反面小图，点开看大图（第 2.5 节），只能查看和下载。
- **置顶**：图标右上角简笔按钮。**排序**：同组内拖动。未置顶且未手动排序的按姓名排序。排序和置顶只存在 `localStorage`。
- **隐藏**：卡片里的垃圾桶把 `driver_notes.hidden` 写成 true，换浏览器仍然隐藏。和删除一样两步确认：第一次点垃圾桶套红框，再点一次才隐藏，点别处取消。派给调度里调度员卡片的垃圾桶（隐藏调度员，`dispatcher_notes.hidden`）同样两步。已隐藏列表可以恢复。
- **解除绑定**（调度台，调度员和公司账户一样）：司导卡片上的垃圾桶只是隐藏；真正解除在「已隐藏」列表里，别人那一行的恢复旁边有垃圾桶，自己这一行没有。两步确认（红框只框垃圾桶图标，不框恢复），调用 `DELETE /api/dispatchers/drivers/{driverId}`。

### 7.8 车辆

- **图标**：沿用司导图标样式，圆圈照片（没有照片用车牌第一个字）和车牌，可置顶。未置顶的按车牌字母顺序（不区分大小写）；置顶组内可拖动排序。存本机 `trailink.dispatcher.vehicleLayout`。
- **车辆日历**：点图标打开，左上角是车牌、编辑和垃圾桶（两步删除）。再点图标收起。
  - 已绑定的日期用已分配颜色填充，写司导名字。打开时今天这一行垂直居中。
  - 司导日历也开着时，车辆日历和司导日历一起滑（双向，见第 7.3 节「上下两张日历一起滑」）；车辆日历画出司导日历的月份。
  - 点车辆日历的日期打开该司导并跳到这一天；点司导日历已绑车的日期打开该车并跳到这一天。
  - 同一天两张订单用了同一辆车：这一天标红，点开后弹出与订单冲突相同的图案选择，司导日历收起，涉及的司导图标换成对应图案，再点一次才解除这一天该车和这张订单的绑定。
- **车辆详情**（编辑进入，同一张 `DispatcherDayCard`）：
  - 添加时即可选最多三张照片，保存车辆时一并上传。详情里并排三张小图，空位用来添加。
  - 点小图时详情撑到页面底部，再出现大图和下载、删除、更新照片（第 2.5 节）。关闭大图后详情还在，缩回打开时的高度。
  - 拉长横条固定在详情框底部，和停用按钮隔开一小段，离框的下边再留 8 像素，不浮在内容上。打开时详情框至少高到能把横条放在停用按钮下方。详情框可以向下超出车辆区盖住司导区，横条和标题栏可以上下拖，松手停在当前位置，关掉后高度恢复。
  - 车牌、车辆信息、共用备注复用 `OrderInfoFields` 的输入框和保存。不写「车辆信息」标题；车辆信息文字在上、备注在下；点与订单相同的编辑图标才出现输入框和保存；没有上下分割线。
  - 最下方横向铺满一个按钮：可用时只显示「停用」（两步确认），停用时只显示「可用」（点一下恢复），写入 `available`。
- **绑定车辆**：车辆图标和车辆日历都可以拖给司导。
  - 拖到还没打开日历的司导上：先打开司导日历并滚到今天，不带动已经打开的订单日历。
  - 拖到已打开的司导日历上的订单：调用 `PUT /api/orders/{orderId}/days/{dayId}/vehicle`，整单绑定还没有车的日期，拆单只绑定这一段还没有车的日期；都已经有车时接口返回 400，不写入。同一天有多张自己的订单时提示，不猜测；不是自己分配的日期提示，不绑定。
  - 车辆分配后仍留在列表。
- **未配车**：车辆标签按钮行最后是「未配车 N单」（单位写明是订单数，司导头像上的「缺 N 天」是天数），N 是自己已派给司导、今天及以后还没配车的订单数（同一张单只算一次），有缺车时字是红色，N 为 0 且没打开时变灰不能点。
  - 点它：车辆区不变；司导区只留下有未配车日期的司导（只看名单里的司导），按最早缺车的日期排序，图标左上角红色小角标「缺 N 天」。都配齐了显示「派出的行程都配好车了」。
  - 这时点开司导，日历直接跳到他第一个未配车的日期（那天写「未配车」）。把车拖上去后看板刷新，数字和角标跟着变，配齐的司导从列表里消失。
  - 再点一次恢复显示全部司导。切到订单标签时不生效，订单标签不提示未配车。
- **车辆标签下的司导日历**：仍画出已分配的订单日期，但操作只针对车辆。
  - 还没有车的自己分配的日期写「未配车」，绑上车后写车牌。别人的日期不写字，也不能拖。
  - 直接拖回车辆区解除这张订单的车辆；按住约 0.5 秒再拖只解除当天。
  - 点日期打开这一天绑定的车辆，并跳到同一天。

## 8. 派给调度（`/company/assign`）

复用同一套 `DispatcherPage`，不复制订单页。

- 右侧图标是本公司调度员（`GET /api/company` 的 `dispatchers`），包含公司账户自己。
- 未分配 = 还没有 `assignedDispatcherUserId` 的本公司订单。
- **分配**：拖订单或拖某一天到调度员，都走 `PUT /api/orders/{id}/dispatcher`，整单覆盖（调度分配不按天）。日历里没有订单的日期直接拖动是滑动；有订单的日期直接拖动是整单；按住约 0.5 秒再拖、松在调度员上仍是整单。
- **收回**：从调度员订单池拖回订单区，清空调度员和各行程日司导。拖到别的调度员上不改派（改派先收回，再从订单区拖给他）。
- **调度员图标**：圆圈显示头像，没有则显示姓名第一个字；圆圈下方优先显示公司给他的备注（`dispatcher_notes`，调度员自己看不到）。可以隐藏和恢复（`dispatcher_notes.hidden`）。垃圾桶两步确认后解除绑定，未完成订单退回公司池；不能解除自己。
- **订单池**（点击调度员打开，不是日历）：
  - 「未完成订单 / 已完成订单」切换该调度员接手的本公司单。
  - 池里图标：第一行公司订单号或共用备注，第二行日期，第三行天数。颜色表示有没有派给司导，不写「已分配」。标题优先公司自己的备注。
  - 名字旁笔记可改公司给他的备注。
  - 卡片与司导详情共用同一套上沿拖动；点池里的订单打开订单日历时，卡片用短动画收回。关掉后高度恢复。
- **订单日历**：日期按有没有司导着色，格子上标司导姓。
- 公司订单备注走 `order_notes` 本公司账户那一行，调度员和司导看不到。

## 9. 登录、公司信息、个人信息

### 9.1 登录

- 未登录进入 `/login`。登录和注册的输入框用 16px，提交后取消焦点。
- 窄屏时卡片靠上，键盘不把按钮挤出屏幕。

### 9.2 公司信息（`/company`）

- 独立白底页，分块与个人信息相同。数据返回前显示「加载中…」，不先闪「还没有加入公司」。
- 下拉切换公司：所属公司以及自己接过订单的公司，选项文字是本人编辑的公司简称。
- **公司资料**：公司头像、公司全名（公司账户可改）、联系方式（手机 / 微信）、公司简称、负责人。
  - 「公司简称」输入框前有标签，最多 20 字，`PUT /api/company/notes`。
- **活动库**（只给公司账户看，`ActivityLibrarySection`）：页面上只有一张入口卡片和「管理活动库」按钮，不在页面上列出活动。
  - 点按钮打开管理弹框（`LibraryManager`，底部弹出，高 86%）：顶部搜索框，下面一行目的地筛选（全部 + 7 个常用目的地，可横向滑动），中间是可滚动的活动列表（名称、英文名、目的地、评分），底部整行「添加活动」。
  - 点列表里的活动或「添加活动」，在管理弹框上面再弹出编辑框（`LibraryActivityEditor`）。点「保存」/「添加到活动库」成功后关闭编辑框，回到管理弹框并刷新列表；删除成功也一样。
  - 中文名、英文名。输入时模糊搜索，黄色框提示「活动库里可能已经有」，点它直接去编辑那一项。
  - 绑定目的地：已选的显示为标签。下面的搜索框搜目的地，空着时列出常用地点；搜不到时可以「新建这个目的地」，填中英文名。
  - 共用备注。
  - 图片：新建时可以先选最多 3 张（压缩后预览，可移除），点「添加到活动库」时一起上传；编辑已有活动时图片即时保存（三格，与车辆照片相同的大图、两步删除、更新、下载），不会关闭编辑框。新建成功但有图片没传上时，编辑框留着并转成编辑这项活动，提示重新添加。
  - 编辑已有活动时有「删除活动」（两步确认）。
- **待批准申请、调度员名单**：只给公司账户看。姓名后显示该用户自己填写的联系方式，没有则写「暂未填写」，不显示用户名。名单包含公司账户自己，自己这一行没有移除。
- **订单记录**（`CompanyOrderRecords`，`GET /api/company/orders`）：
  - 标题右边的范围下拉框跟着角色：公司账户「全部 / 调度中 / 已接单」（`all` / `desk` / `driver`），调度员「调度中 / 已接单」，司导只有一项不显示下拉框。默认是第一项。选过的记在本机（`trailink.company.recordsScope`，不在这个角色的范围里就用默认），换了就重新读取并停到今天；选的和当前一样时不动。长按的操作只给自己管的单（`canEdit` 等由后端给），只是自己跑的单长按不弹。
  - 下拉框左边「导出」（有记录时才有），点开一个小菜单，导出的都是当前范围的全部记录，不只是屏幕上看到的 10 行（`OrderRecordsExport`）：
    - 「导出新表格」：下载默认样式的 Excel（`GET /api/company/orders/export`），文件名「订单记录-调度中-20261111-001130.xlsx」（新西兰时间的日期和时分秒，多次导出不重名）。样式参考调度员手里的表：
      - 列：订单来源（自己给这家公司起的简称）、客人信息（2人）、负责人（司导）、车型、车牌、起止时间（11.11-11.15）、南/北岛、行程路线（完整的共用备注，换行变成空格）、系统订单号（灰色小字，再上传时用来对单）；
      - 浅蓝加粗表头；每年一行绿色年份（整行合并、年份靠右）；数据居中，行程路线左对齐；
      - 冻结表头；打印横向、宽度缩到一页。
    - 「填进我的表格…」：选一个 .xlsx（空表、只有表头、已经有内容的都可以），上传后下载「原文件名-20261111-001134.xlsx」（以原表格的名字为准，加上日期和时分秒；`POST /api/company/orders/export`）：
      - 服务器认出每一列：配了 AI 密钥（和 AI 建单是同一个）时让 AI 看表头和已有的几行，否则按表头文字找；
      - 表里已有的单按「系统订单号」对上（没有这一列时自动加在最右边；没写订单号的行按起止日期和行程开头对，对上的补写订单号），就地更新人数、司导、车型、车牌、日期、南/北岛、行程；订单来源不改，系统里空着的不清空表里的字；
      - 新单接在已有内容后面，下面的「合计」之类往下挪；
      - 新行照已有数据行的样式，跨年时照已有的年份行加一行，日期和人数的写法跟着表里已有的；
      - 空表写默认表头和样式。
    - 完成后提示「新增 n 条，更新 n 条，n 条没有变化」（AI 认的会说明）。只支持 .xlsx，.xls 会提示先另存。手机上同样会下载（系统弹出保存 / 打开）。
  - 表格，列：人数、车型、起止时间（`11.11–11.15`，一天只写一个日期）、南/北岛、行程路线（共用备注前 10 个字，多出的用「…」）、司导、车牌。
    - 没派司导写红色「未派单」，部分没派在司导后面写「· n天未派」；没配车写橙色「未配车」，部分没配写「· n天未配」。
    - 颜色和整个界面一致，不着色：白底表头、灰字。年份变化处插一行年份，左对齐、灰色小字。已经结束的单文字变灰。
    - 点一行（或长按一行）选中：浅灰底；编辑、改日期回来还在。点订单记录表格外面（弹框、长按操作框之外）就取消选中。
    - 跳到调度台：已经选中的那一行，再点司导或车牌就跳到 `/dispatcher`（自己调度台上的单 `onDesk` 跳调度台；公司账户管的其他单——公司池里没人派的、分给调度员的——跳「派给调度」只打开这张订单；没开始、进行中、已结束的都可以；只是自己跑的单不跳。选中后司导、车牌两格里各出现一块铺满格子的圆角白面，浅边框加一点阴影，和界面上的圆角按钮一个风格，按下时变灰）。几位司导、几辆车时点哪个名字开哪个，点在格子空白处开第一个。整单「未派单」时（格子同样是圆角白面），再点就跳过去只打开这张订单。长按弹出操作框后松手那一下不算再点。
      - 点司导：订单 tab，打开这张单和这位司导的详情，司导日历跳到他在这张单上的第一天，订单日历和它对齐（同调度台点订单日期）。
      - 派了司导、整单没配车时点「未配车」：车辆 tab，不开车辆，打开第一位司导的详情，司导日历跳到他在这张单上第一个没配车的日子（方便直接把车拖给他）。
      - 点车牌：车辆 tab，打开这辆车（不在「可用车辆」里时过滤换成「所有车辆」）和它在这张单上第一天的司导，司导日历跳到那一天，车辆日历跟着对齐。
      - 返回：从订单记录跳过来的调度台，页面左上角浮着一个 52px 的圆形返回按钮（固定在屏幕上、盖在其他控件上面、带阴影），图案是带圆勾的返回箭头；点了回到公司信息，订单记录选中跳过去的那一行、表格滚回跳之前的位置，整个页面也滚到这一行（放在屏幕中间）（本标签页 `sessionStorage` 记一次，只有点了返回按钮回来才用，用过就清；自己再打开公司信息时照常停在今天）。直接打开调度台不显示返回按钮。
      - 跳转信息放在路由 state（`dispatcherJump.ts`），调度台第一次读完数据后打开一次，随后从浏览器记录里去掉，刷新不再跳。单子不在调度台上、司导不在司导列表里、车不是自己的时给提示。
  - 行高固定 40px，框高 11 行（表头 + 10 行），上下滑看更多。表格最小宽 720px，手机上框里左右滑看全部列。表头吸顶。
  - 打开时滚到还没结束（结束日期不早于今天）的第一张单，放在表头下面（前面是年份行就连年份一起露出）；后面的单不够多时停在最底。
  - 长按一行约 0.5 秒（手机轻震；手指移动超过 8px 或表格在滚动就取消）弹出操作框，点外面关闭：
    - 「编辑订单」：打开下面的订单弹框（订单信息里有人数、车型、南/北岛；能改日期时有「调整日期」）。保存后订单记录重新读取。
    - 「抢单状态」：沿用调度台的三段按钮（`ShareLevelBar`），点了立即保存。
    - 「退回公司」：第一下变成圆角方形红框「再点一次退回公司」，点别处取消；第二下 `DELETE ?release=true`。
    - 没有可做的操作（司导）时长按不弹。
- **订单弹框**：订单记录里「编辑订单」打开，点外面关闭。
  - 弹框、长按操作框开着时锁住后面的公司信息页（`useLockPageScroll`，html / body `overflow: hidden`），弹框自己 `overscroll-behavior: contain`，在弹框里滑到头也不带动后面。
  - 日期一行右边「调整日期」（订单 `canReschedule` 时有）：打开改日期弹框（`OrderRescheduleDialog`），就是调度台订单卡改日期的同一套——同一张订单日历卡、同一个手势（按住拖整单，长按首尾约 0.5 秒拉长缩短）、同一条按钮条（取消 / 还原 / 保存，要删日子时保存两步红框）、同一个接口 `PUT /api/orders/{id}/dates`。预览、按钮条和保存在 `orderReschedulePreview.tsx`，调度台和弹框共用。保存后订单弹框和订单记录重新读取。
  - 订单信息：共用备注、自己的备注；调度员和公司账户还有人数、车型、南/北岛。
  - 弹框里每个日期后面先是当天活动（活动框留白，多个活动用 `-` 连接，过长只显示开头），再显示当天司导，没派写「未分配」。不另写一行公司订单号。
  - 公司、调度员、司导改的是同一条 `order_activities.content`。
  - 弹框里也可上传订单截图。

### 9.3 个人信息（`/me`）

- 独立白底页，分三块：
  - **资料**：头像、姓名、联系方式；不展示角色。有司导身份时，再上传驾照正面和反面各一张（第 2.5 节），本人可上传、更新、删除。

## 抢单页（`/driver/grab`，`pages/grab/GrabPage.tsx`）

- 入口：右上角「···」菜单里的「抢单」，所有角色都有；页头和账户页一样（标题「抢单」、本人姓名、「我的行程」和「···」）。
- 筛选：全部 / 公司内部 / 面向所有人（只显示有单的等级，带数量；调度自留的单不出现在抢单页），右边「刷新」；下面是可展开的说明。
- 颜色只用三种：黑白灰做底和文字；橙色专门表示抢单（抢单按钮、已抢的单、已抢提示、日历上抢单的日期）；红色只用于日期冲突。筛选选中用深灰。
- 每张单一张卡片（白底、细边框、圆角 16）：
  - 第一行：日期范围（如「11月8日 – 11月10日」）和「N 天 ›」，点它跳到我的行程并用橙色虚线框标出这几天；右上角等级标签（灰底灰字）。
  - 第二行：公司名 · 调度 姓名 · 游客人数；拆单时多一行「拆单：整张订单 N 天，其余已派，这 M 天一起接」。
  - 每天一行：左边日期和星期，中间住宿地第一个字（和日历格子里的浮雕字同一种写法），右边住宿地、活动（含签到 / 预订时间，用 - 连接）、行程说明。
  - 底部：没有冲突时「抢这 N 天」（橙色描边），点一下变成「确认抢这 N 天」（实心橙色）和「取消」，再点才抢；有冲突时冲突那几天标红并写「你这天已有行程（订单名）」，底部提示先在我的行程里取消那一天，按钮换成「去处理」（跳到我的行程冲突那一天，并标出这张单的日期）。
  - 跳到我的行程用 `/driver/calendar?date=停在哪天&grab=日期,日期`：我的行程把 `grab` 里的日期画上橙色虚线框，和已有行程、冲突红色重叠也照样画；日历上方一行「橙色虚线框是抢单的 N 天」和「不再标出」。
  - 已抢的单：卡片橙色虚线框，底部「已抢单，等调度员确认」和「撤回」。
- 顶部浅橙色提示「已抢 N 张单，等调度员确认」和「在我的行程里看」（标出所有已抢单的日期）。调度员确认后，单子从这里消失，出现在我的行程里。
- 抢单失败（调度员改过、出现冲突、不再放出）时提示原因并重新读取列表。
