# Trailink V1 前端设计说明

版本：V1 MVP 第一阶段  
日期：2026-10-23  
状态：当前界面基线

本文档说明本阶段订单与行程界面，不引入复杂日历组件或路线编辑器。

---

## 1. 页面与路由

| 路由 | 页面 | 说明 |
|------|------|------|
| `/orders` | 订单列表 | 查看与删除订单 |
| `/orders/new` | 订单编辑 | 新增订单 |
| `/orders/:orderId` | 订单编辑 | 详情与编辑共用一页 |
| `/drivers` | 司机管理 | 保持现有列表与表单，本轮不改字段 |
| `/driver/calendar` | 司机端日历 | 独立手机界面，不复用调度端布局 |
| `/dispatcher` | 调度台 | 独立白底派单页，不复用订单列表，不另建派单表 |

不另建平行订单详情页。调度员日历本轮仍不实现。

---

## 2. 订单列表

表格列：

- 系统订单号（可点击进入编辑）
- 平台订单号
- 来源公司
- 开始日期
- 行程天数
- 游客人数
- 操作：编辑、删除

行程天数取接口返回的 `dayCount`，由实际行程日期条数计算，不由开始/结束日期相减。

---

## 3. 订单编辑 / 详情

同一页面分三块。

### 3.1 订单基本信息

可编辑：平台订单号、来源公司、起始日期、游客人数、备注。  
系统订单号只读展示。前端不得提交 `orderNo`。

保存订单后才能增删行程。创建订单不再按结束日期自动铺天。

### 3.2 行程日期缩略卡片

按日期连续排列小卡片，每张显示：

- 日期
- 结束地点
- 司机
- 活动项目数量

点击卡片选中该日。支持新增行程日、删除行程日、整单派司机。

### 3.3 当日行程

选中日期后展示并可直接编辑：

- 当日行程描述
- 结束地点
- 当日司机（按天派单）
- 活动项目列表
- 电子票路径输入（只保存 `ticketPath`）

活动项目可新增、修改、删除、拖动排序。字段：活动内容、承办方、预订时间、签到时间、电子票路径、展示顺序。

日期提交 `YYYY-MM-DD`。预订/签到时间提交 `YYYY-MM-DDTHH:mm:ss`，禁止使用 `toISOString()` 或带时区偏移的字符串。

不实现实际签到打卡，不实现独立文件管理或上传器。`ticketPath` 只作为预留字符串入口。

---

## 4. 交互约定

- 整单派单调用 `PUT /api/orders/{orderId}/driver`。
- 按天派单通过更新当日行程的 `driverId`。
- 订单详情一次拉取主体、行程和活动，不再逐条请求活动。
- 使用 Ant Design 表单、日期选择与卡片，不引入第三方日历或地图。
- 文案使用简体中文。

---

## 5. 司机端日历

独立页面，不使用调度端顶栏。

- 白底独立页，标题为「我的行程」。月份上下连续滚动，默认停在当前月并尽量露出今天。当天用浅灰细边框标出，不另加色块或加粗数字。
- 七列周一至周日；有行程日期用圆角药丸格填充，空白日期只显示数字。
- 已完成 / 未完成颜色可分别选择，默认薄荷绿 / 浅蓝，保存在 `localStorage`。月份标题旁不重复图例，只保留页面右下角两个按钮。
- 点击有行程日期在当月日历下方展开圆角卡片，只展示已添加活动的文本和一套「添加活动」。同一天有空行程时不另画添加按钮。活动可拖动排序，顺序写入 `sort_order`，不按时间排。不展示标题、目的地、描述、日期和订单号。再点同一天收起卡片。
- 标题下可选择当前查看的司导（本机记住，不是登录身份）。日历只显示该司导 `itinerary_days.driver_id` 的日期，数据来自 `GET /api/orders` 与 `GET /api/drivers`，与调度台同一套行程日。
- 右上角为「行程管理」：下拉可输入订单号领取已有订单（`PUT /api/orders/{orderId}/driver`），或在日历上拖选起止日期后走共用的 `createOrderWithDays`（内部仍是 `POST /api/orders` 与 `POST /api/orders/{orderId}/days`，并写当前司导 `driverId`）；也可点「取消行程」后点击某天，只解除当前司导在该单上的日期（`PUT` 当日 `driverId: null`），其他司导的日期不受影响。取消在有效点击或键盘 Enter / Space 后触发，滑动日历不解除绑定。框选添加仍用按住拖选。前端不封装 `claim` / `range` 客户端。
- 颜色选择由底部「已完成」「未完成」打开。不把前端 `driverId` 当作登录身份。
- 电子票本阶段只保存路径字符串，不打开文件。

## 6. 调度台

独立页面，不使用订单列表顶栏。风格与司机日历一致：白底、圆角大图标、底部色点改色。

- 顶部展示当前调度员姓名（本机可改，开发预览，不是登录身份）。
- 上半区订单、下半区司导。订单区按钮顺序为「创建订单」「未分配订单」「所有订单」；「已分配颜色」只在选中「所有订单」时出现。
- 未完成按结束日期尚未早于今天；进行中订单排最前，再按出发日期靠近今天排序。
- 点击订单图标，在订单区域弹出覆盖该区的日历卡片；点击司导图标，在司导区域弹出覆盖该区的未来行程卡片。两卡同时打开时，滑动订单日历会按月份带动司导日历，滑动司导日历不带动订单日历。订单、司导、创建订单日历里当天都用与司机日历相同的浅灰细边框标出。订单卡片名字旁的笔记图标可改平台订单号（公司订单号）和备注，点保存走现有 `PUT /api/orders/{id}`，保存后回到日历。删除按钮在编辑按钮右侧，样式和间距与司导卡移除一致，确认后走现有 `DELETE /api/orders/{id}`。点击某一天打开独立的当日行程卡片（同一套 `DriverDayEditor`），不和订单信息编辑叠在同一张卡里。司导卡片备注仍是名字右侧简笔图标。图标网格保持原位，不另占下方空间。
- 拖动订单卡片或未分配订单图标到司导图标；若司导卡片已打开，拖到司导区域即整单分配。调用现有 `PUT /api/orders/{orderId}/driver` 且 `failOnConflict: true`。日期冲突返回 409，不写入，不关闭卡片。
- 拖动订单或司导日历里的某一天到司导，调用现有 `PUT /api/orders/{orderId}/days/{dayId}` 且 `failOnConflict: true`，只改该日 `driverId`。不新建订单。
- 从司导日历把某一天拖到订单区域：若该单是拆单，只把当天 `driverId` 置空；若该日未拆单（整单都是这位司导），调用 `PUT /api/orders/{orderId}/driver` 清空整单。不关闭卡片。拆单判定与当日编辑器共用 `isSplitOrder`：多个司导，或已派天数小于行程天数。
- 未分配订单包含尚未派完的单：全部未派，或拆单后仍有空日期。全部日期都已派的不出现在未分配。
- 「所有订单」列出有行程日的全部订单。整单已派用本机保存的背景色。拆单或只派了部分日期时，图标本体保持白底，右上角用直线切开一块已分配色，不按天数比例给整块上色。订单日历里已派日期与未派日期仍用这两种颜色。改色方式与司机日历「已完成 / 未完成」相同。部分日期已派时显示「拆分」。
- 「创建订单」打开覆盖订单区的日历卡片，操作与司导「行程管理」框选建单相同：按住拖选起止日期后确认，确认按钮在卡片右下角。走同一套 `createOrderWithDays`，不写 `driverId`，新单出现在未分配。一次最多 31 天。不另建创建接口或页面。
- 司导置顶是图标右上角简笔按钮；移除在司导卡片里、备注按钮右侧并留间距，避免误触。可拖动同组排序。未置顶且未手动排序的按姓名排序。布局只存在 `localStorage`。

## 7. 本阶段不做

- 调度员日历
- 订单附件上传界面
- 路线编辑器
- 复杂状态标签
- 登录注册与权限界面
