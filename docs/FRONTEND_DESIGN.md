# Trailink V1 前端设计说明

版本：V1 MVP 第一阶段  
日期：2026-10-23（2026-11-01 按页面和功能拆分小节，交互不变）  
状态：当前界面基线

本文写界面和交互。业务规则（谁能做什么）以 `PRD.md` 为准。不引入第三方日历组件、地图或路线编辑器。

---

## 1. 页面与路由

| 路由 | 页面 | 谁能打开 |
|------|------|----------|
| `/login` | 登录 / 注册（司导或公司注册，调度员由批准产生） | 未登录 |
| `/driver/calendar` | 我的行程：本人的行程日历 | 全部角色 |
| `/dispatcher` | 调度台 | 公司、调度员 |
| `/company/assign` | 派给调度：复用调度台页面，右侧是本公司调度员 | 仅公司 |
| `/company` | 公司信息 | 全部角色 |
| `/me` | 个人信息 | 全部角色 |

- 路由、菜单和角色准入只在 `frontend/src/navigation.ts` 定义。
- 接口类型从后端 OpenAPI 生成到 `frontend/src/api/generated/`；`types.ts` 不手写后端 DTO，只放别名、响应归一化和纯 UI 模型。
- 不提供 `/orders` 表格页或 `/orders/:orderId` 编辑页。进行中的单在调度台，历史单在公司信息，本人行程在 `/driver/calendar`。旧地址重定向到角色首页。行程天数取接口返回的 `dayCount`。
- 公司登录后进入调度台，司导登录后进入我的行程。

## 2. 全局约定

### 2.1 页面外观与菜单

- 调度台、我的行程、公司信息、个人信息都是独立白底页，不使用 Ant Design 顶栏。风格：白底、圆角大图标、底部色点改色。
- 右上角「我的行程」单独成按钮；旁边三点图标展开下拉：派给调度（仅公司）、调度台、公司信息、个人信息、退出。
  - 当前页不出现在下拉里；司导看不到调度台；已在行程页时不再重复「我的行程」。
  - 页面自己的操作（行程管理、创建订单）留在外面。
- 文案使用简体中文。

### 2.2 数据刷新

- 进入调度台、派给调度、我的行程、公司信息或个人信息时，重新读取这一页的数据。
- 从其他窗口回到当前页也会再读一次。
- 已经改过、还没保存的输入保持不动。

### 2.3 手机与触屏

- 视口固定为设备宽度和 1 倍缩放，键盘弹出时不改变页面尺寸。
- 输入框在窄屏和触屏上用 16px，避免浏览器聚焦时整页放大。点进订单编辑时页面不放大，仍按屏幕高度拉伸。
- 登录、调度台、派给调度、我的行程、公司信息、个人信息：长按输入框以外的地方不选择文字，也不弹出系统菜单。界面里已有的长按操作照常（例如按住约 0.5 秒拖选日期）。输入框、文本域和下拉框仍可选中文字。

### 2.4 通用操作手势

- **触屏拖动前按住约 0.5 秒**：订单图标、司导图标、调度员图标、车辆图标、排序都是这样。未满 0.5 秒时上下滑动仍滚动对应区域。鼠标按下即可拖。
- **拖动把手**：带 ⋮⋮ 把手的列表（活动选择框、已选活动、当日活动），按住把手立即拖动，把手这一小块不滚动页面；手指在把手以外的地方是滚动，长按约 0.5 秒才拖动。同一次手指移动只和经过的那一项交换一次，避免来回跳。
- **卡片头**：只有能拖动的卡片头（调度台拖订单、拉高司导 / 车辆卡片）按住时不滚动页面；不能拖动的卡片头（例如我的行程当日详情里的订单号一行）按住空白处仍可上下滑动。
- **两步确认**：解除、删除、停用这类操作，第一次点击只给按钮（或日期）套上红框，再点一次才执行，不弹框。点到别处取消红框。
- **点空白处关闭**：订单、司导、车辆、调度员详情，点弹框外没有按钮的空白处关闭；点按钮仍执行按钮自己的操作。

### 2.5 照片查看（车辆照片、驾照照片共用）

- 小图点开后看大图，大图按横向比例固定展示，竖图也缩到这个高度，切换时大小不变。
- 下方一条横杠对应一张照片，长短相同，当前这张更深。左右滑动换一张。
- 可下载；有权限时可删除（两步确认）和更新。
- 点详情框里照片和按钮以外的空白处关闭大图。
- 上传前在页面里压成 jpg，最长边 1600，不把原图发给服务器。压缩只在后台线程里做，浏览器不支持时直接报错，不退回主线程；超过 20 秒停掉并提示换一张小一些的照片。正在处理的那一格转圈，其他格不受影响。项目默认在手机浏览器上使用。

## 3. 订单信息卡（`OrderInfoPanel` / `OrderInfoFields`）

调度台订单卡、我的行程当日卡、公司信息订单弹框共用这一套，保存走 `updateOrderInfo` → `PUT /api/orders/{id}`。

- **显示名**：由后端给出（`label`），前端只截断。订单图标、卡片头、公司信息订单图标和卡片、领取成功提示、取消行程和冲突提示都不展示系统订单号。有公司订单号用公司订单号，否则用共用备注，都没有就空着，超过 12 字截断。领取框只提示输入公司订单号。
- **卡片头**：名字旁蓝色笔记图标打开编辑，编辑项在卡片可滚动区域里，手机上可以滑到公司、订单号、备注和截图。收起时备注显示在订单号之下、日期信息之上。
- **调度台可改**：所属公司、公司订单号、自己的调度备注 `notes`（`order_notes`，互不可见），上传订单截图。保存后回到日历。
- **我的行程可改**：司导备注 `driverNotes` 和订单截图，不能改公司订单号。点开某一天时，公司订单号下面显示当天调度员的姓名和联系方式。
- **共用备注** `sharedNotes`：三方都能看、都能改，排在各自备注上方。
- 没有内容时备注输入框只有一行，有内容再跟着增高。
- **所属公司**：调度员搜索公司名称，点选后立即用 `PUT /api/orders/{id}` 写入 `companyId`，不必再点保存。公司账户看所属公司只读。

## 4. 当日行程（`DriverDayEditor`）

点击某一天打开独立的当日行程卡片，不和订单信息编辑叠在同一张卡里。

- **住宿位置**（写入 `endLocation`）：一行按钮 基、凯、特、瓦、皇、蒂、但（读 `GET /api/places`），或输入其他地点。再点一次已选中的按钮就清空，当天不再显示浮雕字。
- **当天车辆**（只在我的行程）：住宿位置按钮下方，若这一天已绑车，同一行紧凑显示车牌和型号（`vehicles.info`），下一行显示车辆共用备注。没有绑车不显示。
- **活动**：可新增、修改、删除、拖动排序（写入 `sort_order`）。字段：活动内容、承办方、预订时间、签到时间、电子票。电子票上传后可打开查看。
  - 「添加活动」弹出活动选择框（`pages/library/ActivityPicker`，底部弹出）：
    - 按住宿位置列出当地活动库活动，显示评分。
    - 列表顺序：先按本人拖出来的顺序，其余按评分。按住 ⋮⋮ 或长按约 0.5 秒拖动调整，松手后保存到账户（按目的地分开）。
    - 点选多选，圆圈里标出点选先后；选中的同时放进下方「已选」。
    - 「已选」是这一次要添加的顺序：按住 ⋮⋮ 或长按拖动调整，× 移除。确认后按「已选」的顺序加到这一天已有活动后面。
    - 顶部搜索整个活动库；「手动填写」打开原来的填写表单。
  - 已添加的活动紧凑两行：第一行是 ⋮⋮ 把手和活动名（有承办方、时间时在名字下面小字）；第二行是右对齐的小按钮：评价（只有活动库来的才有）、编辑（承办方、时间）、上传电子票、删除（红字）。
  - 按住 ⋮⋮ 立即拖动排序，或在活动其他位置长按约 0.5 秒后拖动（`useHoldReorder`）。按住前手指移动是滚动页面；拖动结束后吞掉紧跟的点击。
  - 评价框（`ActivityReview`）：活动名、英文名、目的地、平均分、共用备注、图片；我的 1–5 星和评价文字；所有人的评价。
- 日期提交 `YYYY-MM-DD`。预订 / 签到时间提交 `YYYY-MM-DDTHH:mm:ss`，禁止使用 `toISOString()` 或带时区偏移的字符串。
- 订单最后一天起满 7 天后，电子票和订单截图不再提供查看，头像仍在。

## 5. 日历通用

调度台的订单、司导、车辆、创建订单日历和我的行程日历共用以下规则。

- **范围**：月份上下连续滚动，不切换单月。从半年前画到半年后，含当前月共十三个月。已有行程更早或更晚时仍画出来。
- **今天**：浅灰细边框标出，不另加色块或加粗数字。
- **有行程的日期**：圆角方格填充；空白日期只显示数字。
  - 订单第一天沿格子左缘、最后一天沿格子右缘用加深的填充色描边，两边不相接，单日订单也不会连成整圈。
- **日期文字**（`CalendarDayCaption`）：数字下显示分配人姓名（优先 `assignedByName`，否则 `createdByName`）。我的行程再加上订单所属公司：公司名和调度员名连写，超过 6 个字且本人写了公司简称时，改成「简称-调度员名」。
- **颜色**：
  - 我的行程、调度台司导详情：早于今天用「已完成」色，今天和之后用「未完成」色。默认薄荷绿 / 浅蓝，由页面右下角「已完成」「未完成」两个按钮改色，存在 `localStorage` 的 `trailink.driverCalendar.colors.v2`。月份标题旁不重复图例。
  - 调度台订单日历：已派日期用「已分配颜色」，未派日期用另一种颜色。
- **住宿位置浮雕**：写了住宿位置的日期叠该地点第一个字，半透明。
  - 调度台司导详情日历和我的行程日历有一条竖向滑条（`calendarInk`），相对所在卡片垂直居中，滑条本身 75% 透明度。
  - 上下拖调节：向上日期文字更明显、浮雕更淡，向下相反。触屏按下即可上下拖。
  - 滑条只影响有浮雕字的日期：日期和派出人在 8%–100% 之间变化，浮雕字和天气在 70%–6% 之间变化。没有浮雕字的日期（空白日期、没写住宿位置的日期）始终清楚，用来认时间。
  - 左右拖过一小段后松手，滑条停在那一侧。触屏左右拖需先按住约 0.5 秒，鼠标按下即可拖。
  - 透明度存 `trailink.calendar.inkBalance`（没有记录时停在正中），左右位置存 `trailink.calendar.inkSide`。
- **冲突日期**（同一司导同一天多张单，`ConflictDatePopover`）：
  - 填成红色。点该日期，在原位置弹出多个同日按钮，并关闭已经打开的订单详情。
  - 调度台：每个按钮一个居中的镂空图案对应一张订单，画成固定大小的正方形，外圈比中间文字更大，中间留空，不压住文字，不随按钮拉宽或拉高，不平铺；梅花中心同样镂空。图案按全部冲突订单固定排序，换日期也不变。前四种是扑克牌黑桃、红心、方块、梅花，第五张起用麻将牌图案。对应订单图标同时换成同样的图案。
  - 调度台按钮文字：自己派出的第一行是日期，第二行与我的行程日期格同一套文字；不是当前调度员派出、无权移除的不显示文字。
  - 我的行程：按钮不画图案，第二行与普通日期格一样显示调度员名字，按各订单自己的起始日期从早到晚排列。
  - 点一个按钮先套红框，再点一次才 `PUT` 这一天 `driverId: null`，按拆单处理。卡片保持打开。
- **框选日期建单**（我的行程「行程管理」和调度台「创建订单」共用）：
  - 鼠标按下即拖选。苹果和安卓触屏按住不动约 0.5 秒后才开始拖选，未满时滑动仍滚动页面，点一下只选中当天。
  - 范围跟着手指下的日期扩展，拖到上下边缘时日历跟着滚动，当前选到的日期留在可视区域里。
  - 一次最多三个月：结束日可以落到开始日三个月后的同一天，月底没有这一天时落到该月最后一天。
  - 走共用的 `createOrderWithDays`（内部是 `POST /api/orders` + 逐日 `POST /api/orders/{orderId}/days`）。前端不封装 `claim` / `range` 客户端。

## 6. 我的行程（`/driver/calendar`）

- 标题「我的行程」。默认停在当前月并尽量露出今天。七列周一至周日。
- 只显示登录用户本人 `driver_id` 的日期，已结束的单也留在对应日期上，用「已完成」色。页面数据只读 `GET /api/orders`，不拉司导列表，不切换他人；不把前端 `driverId` 当作登录身份。
- **当日卡片**：点击有行程的日期，在当月日历下方展开圆角卡片，头部是订单信息卡（第 3 节），下面是已添加活动和一套「添加活动」（第 4 节）。同一天有空行程时不另画添加按钮。再点同一天收起。
  - 卡片落在可视区域下方时，点开的日期旁出现「详情」向下箭头，放不下就停在日历可视区域底部，点一下滚到卡片；卡片顶部已经露出来时不显示。
  - 同一订单还有其他人分担时，提示拆分。
- **行程管理**（右上角下拉）：
  - 订单号和输入框同一行，「领取」与「取消行程」并排。取消行程文字在按钮内居中，按钮高度和字号不变，预先留出确认按钮高度，拖选时不因按钮出现而挤走日历。
  - **领取**：输入公司订单号，调用 `PUT /api/orders/{orderId}/driver`。成功后日历跳到该单首日并展开当日卡片。
  - **框选建单**：见第 5 节，写当前用户 `driverId`，不写 `companyId`。
  - **取消行程**：点「取消行程」后点击某天，只解除本人在该单上的日期（`PUT` 当日 `driverId: null`），其他司导的日期不受影响。由有效点击或键盘 Enter / Space 触发，滑动日历不解除。
- **取消某一天**：点开某一天后，备注图标右侧的垃圾桶先把这一天套上红框，再点一次该日期才解除当天这一条，同样 `PUT` `driverId: null`。其余日期不动，订单成为拆单，调度台未分配重新列出这张单。
- 日历格子上不显示车牌。
- **天气**：后端给出天气的日期（地点规则见 PRD 第 8 节），天气和浮雕字一起放在背景层（`calendar-day-backdrop`）：浮雕字缩小贴格子上沿，天气（`calendar-day-weather`）贴下沿，透明度和浮雕字同一个变量，跟着滑条一起变；日期和派出人的位置不变，照常叠在上面。页面底部左侧注明数据来源（「天气数据：MET Norway」等，读 `GET /api/weather/source`；没有配置天气时不显示）。天气文字照后端给的显示，不做转换。调度台的日历不显示天气。

## 7. 调度台（`/dispatcher`）

### 7.1 布局

- 左上角是当前登录用户姓名（派给调度是本公司名称），读登录身份。
- 上半区订单（或车辆），下半区司导。
- 订单区用同一行标签切换「订单 / 车辆」，两个标签不换行；标签下面才是当前页的操作按钮。派给调度没有车辆标签。
  - 订单：「创建订单」「未分配订单」「所有订单」；「已分配颜色」只在「所有订单」时出现。
  - 车辆：「添加车辆」「可用车辆」「所有车辆」。控件同一套 `dispatcher-chip`。
- 订单区和司导区的长说明默认收起，用下箭头展开，展开后改为上箭头收起。
- 订单列表和车辆列表分开请求，车辆失败不清空订单。

### 7.2 订单列表

- **未分配**：全部未派、拆单后仍有空日期的订单，以及同一司导日期重叠的冲突订单（即使日期都已派完），不论结束日是否已过。
- **所有订单**：有行程日、且尚未成为历史单（已派完且结束日早于今天）的订单。
- 排序：进行中订单排最前，再按出发日期靠近今天排序。未完成 = 结束日期尚未早于今天。
- **图标颜色**：
  - 整单已派：「已分配颜色」背景。颜色读当前用户 `assignedColor`，点选走 `PUT /api/auth/assigned-color`，每人一条，不写本机。改色方式与我的行程「已完成 / 未完成」相同。
  - 拆单或只派了部分日期：图标本体保持白底，右上角用直线切开一块已分配色，不按天数比例上色，并显示「拆分」。
  - 同一司导有重叠日期的订单：同样的切角，颜色为红色。

### 7.3 订单卡片

- 点击订单图标，在订单区弹出覆盖该区的日历卡片，头部是订单信息卡（第 3 节）。
- 已派给司导的订单同时打开该司导的行程，并滚到这张订单里该司导的日期。拆单时打开第一个已派日期所属的司导；第一个已派日期早于今天时，滚到该司导在这张单上今天或之后的第一天。没有派司导的只打开订单卡片。
- 删除按钮是简笔垃圾桶，在编辑按钮右侧，样式和间距与司导卡移除一致。走同一 `DELETE /api/orders/{id}`：
  - 调度员 + 已绑公司：按钮为「退回公司」，确认后只解绑并退回公司池。
  - 调度员 + 未绑公司：「删除订单」，确认后真正删掉。
  - 公司账户：始终是「删除订单」。
- 点击某一天打开独立的当日行程卡片（第 4 节）。
- 订单日历和司导日历同时打开时，滑动订单日历按月份带动司导日历，反向不同步。司导卡会画出当前打开订单覆盖的月份，即使该司导当月没有行程。

### 7.4 司导卡片

- 点击司导图标，在司导区弹出覆盖该区的行程卡片，画出这位司导的全部行程，包括已完成日期和进行中订单已过去的日期，不限本公司。着色同我的行程。
- 打开时：订单日历未打开则滚到今天；订单日历已打开时，订单日历保持原位，司导日历滚到订单日历当前的日期位置。
- 姓名下显示该司导自己填写的联系方式。
- **卡片高度**：顶部横条和标题栏可以向上拖，卡片跟着变高，最多盖住整个订单区；松手停在当前位置，往下拖回到下半区。点自己分配的日期或冲突日期时，卡片用一段短动画收回下半区，让订单区露出来。关掉后高度恢复。
- **日期**：
  - 自己分配的日期：与我的行程日期格同一套文字；点一下在订单区打开这张订单；可以拖回订单区取消。
  - 其他人分配的日期：只着色，不写公司名或调度员姓名；不能点开，不能拖动或移除，点一下只提示，触屏仍可滑动。有住宿位置时只叠地点第一个字。
- 卡片备注按钮是名字右侧蓝色简笔图标；移除按钮在备注按钮右侧并留间距，避免误触。

### 7.5 拖拽派单

- **整单派给司导**：拖动订单卡片或订单图标到司导图标；司导卡片已打开时，拖到司导区域即分给该司导。调用 `PUT /api/orders/{orderId}/driver`，日期重叠也写入。
- **按天派给司导**：从订单日历或司导日历拖某一天到司导，调用 `PUT /api/orders/{orderId}/days/{dayId}`，只改该日 `driverId`。
- 订单 / 司导详情日历里的触屏规则：没有订单的日期直接拖动是滚动；有订单的日期直接拖动是整单；按住约 0.5 秒再拖是这一天。鼠标拖某一天只改那一天。
- **从司导卡片拖回订单区（取消）**：
  - 只有自己分配的日期能拖。整单里任一已派日不是当前调度员派的，整单不会被拖起。
  - 鼠标：拆单只把当天 `driverId` 置空；未拆单（整单都是这位司导且同一人派出）调用 `PUT /api/orders/{orderId}/driver` 清空整单。
  - 触屏：直接拖清空整单，按住约 0.5 秒再拖只清空当天。
  - 不关闭卡片。拆单判定与当日编辑器共用 `isSplitOrder`。
- 不新建订单。

### 7.6 创建订单

- 「创建订单」在未分配左侧，打开覆盖订单区的日历卡片，打开时停在今天。
- 框选规则见第 5 节。确认按钮在卡片右下角。
- 不写 `driverId`，也不默认写 `companyId`；新单出现在未分配，所属公司须事后搜索绑定。

### 7.7 司导名单

- 司导图标只来自已向当前登录账户申请并批准的人（含本人）。公司账户只看到向公司账户申请并批准的人。
- 圆圈显示该司导上传的头像，没有头像则显示姓名第一个字。圆圈下方优先显示当前调度员自己给他写的备注（`driver_notes`，接口仍用 `notes`），没有才显示姓名；超过 12 字截断。卡片标题、恢复隐藏仍用姓名。
- 编辑司导备注时，能看到这位司导的驾照正反面小图，点开看大图（第 2.5 节），只能查看和下载。
- **置顶**：图标右上角简笔按钮。**排序**：同组内拖动。未置顶且未手动排序的按姓名排序。排序和置顶只存在 `localStorage`。
- **隐藏**：卡片里的移除把 `driver_notes.hidden` 写成 true，换浏览器仍然隐藏。已隐藏列表可以恢复。
- **解除绑定**（只有调度员）：已隐藏列表里别人那一行的恢复旁边有垃圾桶，自己这一行没有。两步确认（红框只框垃圾桶，不框恢复），调用 `DELETE /api/dispatchers/drivers/{driverId}`。公司账户的已隐藏列表只有恢复。

### 7.8 车辆

- **图标**：沿用司导图标样式，圆圈照片（没有照片用车牌第一个字）和车牌，可置顶。未置顶的按车牌字母顺序（不区分大小写）；置顶组内可拖动排序。存本机 `trailink.dispatcher.vehicleLayout`。
- **车辆日历**：点图标打开，左上角是车牌、编辑和垃圾桶（两步删除）。再点图标收起。
  - 已绑定的日期用已分配颜色填充，写司导名字。打开时今天这一行垂直居中。
  - 司导日历也开着时，滑动司导日历按月份带动车辆日历，反向不同步；车辆日历画出司导日历的月份。
  - 点车辆日历的日期打开该司导并跳到这一天；点司导日历已绑车的日期打开该车并跳到这一天。
  - 同一天两张订单用了同一辆车：这一天标红，点开后弹出与订单冲突相同的图案选择，司导日历收起，涉及的司导图标换成对应图案，再点一次才解除这一天该车和这张订单的绑定。
- **车辆详情**（编辑进入，同一张 `DispatcherDayCard`）：
  - 添加时即可选最多三张照片，保存车辆时一并上传。详情里并排三张小图，空位用来添加。
  - 点小图时详情撑到页面底部，再出现大图和下载、删除、更新照片（第 2.5 节）。关闭大图后详情还在，缩回打开时的高度。
  - 拉长横条固定在详情框底部，和停用按钮隔开一小段，离框的下边再留 8 像素，不浮在内容上。打开时详情框至少高到能把横条放在停用按钮下方。详情框可以向下超出车辆区盖住司导区，横条和标题栏可以上下拖，松手停在当前位置，关掉后高度恢复。
  - 车牌、车辆信息、共用备注复用 `OrderInfoFields` 的输入框和保存。不写「车辆信息」标题；车辆信息文字在上、备注在下；点与订单相同的编辑图标才出现输入框和保存；没有上下分割线。
  - 最下方横向铺满一个按钮：可用时只显示「停用」（两步确认），停用时只显示「可用」（点一下恢复），写入 `available`。
- **绑定车辆**：车辆图标和车辆日历都可以拖给司导。
  - 拖到还没打开日历的司导上：先打开司导日历并滚到今天，不带动已经打开的订单日历。
  - 拖到已打开的司导日历上的订单：调用 `PUT /api/orders/{orderId}/days/{dayId}/vehicle`，整单绑定还没有车的日期，拆单只绑定这一段还没有车的日期；都已经有车时接口返回 400，不写入。同一天有多张自己的订单时提示，不猜测；不是自己分配的日期提示，不绑定。
  - 车辆分配后仍留在列表。
- **车辆标签下的司导日历**：仍画出已分配的订单日期，但操作只针对车辆。
  - 还没有车的自己分配的日期写「未配车」，绑上车后写车牌。别人的日期不写字，也不能拖。
  - 直接拖回车辆区解除这张订单的车辆；按住约 0.5 秒再拖只解除当天。
  - 点日期打开这一天绑定的车辆，并跳到同一天。

## 8. 派给调度（`/company/assign`）

复用同一套 `DispatcherPage`，不复制订单页。

- 右侧图标是本公司调度员（`GET /api/company` 的 `dispatchers`），包含公司账户自己。
- 未分配 = 还没有 `assignedDispatcherUserId` 的本公司订单。
- **分配**：拖订单或拖某一天到调度员，都走 `PUT /api/orders/{id}/dispatcher`，整单覆盖（调度分配不按天）。日历里没有订单的日期直接拖动是滑动；有订单的日期直接拖动是整单；按住约 0.5 秒再拖、松在调度员上仍是整单。
- **收回**：从调度员订单池拖回订单区，清空调度员和各行程日司导。
- **调度员图标**：圆圈显示头像，没有则显示姓名第一个字；圆圈下方优先显示公司给他的备注（`dispatcher_notes`，调度员自己看不到）。可以隐藏和恢复（`dispatcher_notes.hidden`）。垃圾桶两步确认后解除绑定，未完成订单退回公司池；不能解除自己。
- **订单池**（点击调度员打开，不是日历）：
  - 「未完成订单 / 已完成订单」切换该调度员接手的本公司单。
  - 池里图标：第一行公司订单号或共用备注，第二行日期，第三行天数。颜色表示有没有派给司导，不写「已分配」。标题优先公司自己的备注。
  - 名字旁笔记可改公司给他的备注。
  - 卡片与司导详情共用同一套上沿拖动；点池里的订单打开订单日历时，卡片用短动画收回。关掉后高度恢复。
- **订单日历**：日期按有没有司导着色，格子上标司导姓。
- 公司订单备注走 `order_notes` 本公司账户那一行，调度员和司导看不到。

## 9. 登录、公司信息、个人信息

### 9.1 登录

- 未登录进入 `/login`。登录和注册的输入框用 16px，提交后取消焦点。
- 窄屏时卡片靠上，键盘不把按钮挤出屏幕。

### 9.2 公司信息（`/company`）

- 独立白底页，分块与个人信息相同。数据返回前显示「加载中…」，不先闪「还没有加入公司」。
- 下拉切换公司：所属公司以及自己接过订单的公司，选项文字是本人编辑的公司简称。
- **公司资料**：公司头像、公司全名（公司账户可改）、联系方式（手机 / 微信）、公司简称、负责人。
  - 「公司简称」输入框前有标签，最多 20 字，`PUT /api/company/notes`。
- **活动库**（只给公司账户看，`ActivityLibrarySection`）：页面上只有一张入口卡片和「管理活动库」按钮，不在页面上列出活动。
  - 点按钮打开管理弹框（`LibraryManager`，底部弹出，高 86%）：顶部搜索框，下面一行目的地筛选（全部 + 7 个常用目的地，可横向滑动），中间是可滚动的活动列表（名称、英文名、目的地、评分），底部整行「添加活动」。
  - 点列表里的活动或「添加活动」，在管理弹框上面再弹出编辑框（`LibraryActivityEditor`）。点「保存」/「添加到活动库」成功后关闭编辑框，回到管理弹框并刷新列表；删除成功也一样。
  - 中文名、英文名。输入时模糊搜索，黄色框提示「活动库里可能已经有」，点它直接去编辑那一项。
  - 绑定目的地：已选的显示为标签。下面的搜索框搜目的地，空着时列出常用地点；搜不到时可以「新建这个目的地」，填中英文名。
  - 共用备注。
  - 图片：新建时可以先选最多 3 张（压缩后预览，可移除），点「添加到活动库」时一起上传；编辑已有活动时图片即时保存（三格，与车辆照片相同的大图、两步删除、更新、下载），不会关闭编辑框。新建成功但有图片没传上时，编辑框留着并转成编辑这项活动，提示重新添加。
  - 编辑已有活动时有「删除活动」（两步确认）。
- **待批准申请、调度员名单**：只给公司账户看。姓名后显示该用户自己填写的联系方式，没有则写「暂未填写」，不显示用户名。名单包含公司账户自己，自己这一行没有移除。
- **订单**：圆角图标，三行是公司订单号或共用备注、起始日期、天数。点开弹框，点外面关闭。
  - 弹框里每个日期后面先是当天活动（活动框留白，多个活动用 `-` 连接，过长只显示开头），再显示当天司导，没派写「未分配」。不另写一行公司订单号。
  - 公司、调度员、司导改的是同一条 `order_activities.content`。
  - 弹框里也可上传订单截图。

### 9.3 个人信息（`/me`）

- 独立白底页，分三块：
  - **资料**：头像、姓名、联系方式；不展示角色。有司导身份时，再上传驾照正面和反面各一张（第 2.5 节），本人可上传、更新、删除。
  - **登录信息**：登录用户名、登录密码。当前密码和新密码都明文显示。
  - **申请**：搜索调度员申请成为司导；搜索公司申请成为调度员。调度员在这里批准申请人，申请行显示姓名和联系方式，不显示用户名。
- 头像上传后服务端压缩再展示。
- 改名后调度台司导卡与本人行程用同一姓名。
